# PDF 요구조건 간결화 검증 — 2026-10-29

정보는 `항목: 기대값`, 시각 조건은 짧은 조건문으로 입력합니다. `[필수]`나 `/ 판단 기준: …`를 입력 문자열에 덧붙이지 않습니다. 수준·설명·예외는 `document_condition`에 보존하고 기준 확정 화면과 결과 화면의 **상세 기준**에서 표시합니다.

LLM에는 행의 전체 기대 내용인 `requirement`, 짧은 값 목록인 `values`, 판단 설명인 `inspection`을 분리해 요청합니다. 서로 모두 필요한 장소 목록은 각각 입력하되, OR 대안·한 장소의 정식 명칭·협연 출연진·파일 규격·시각 조건의 술어는 조각내지 않습니다. 사람이 문구를 수정하면 이전 구조를 제거하고 서버도 표시 문구와 기대값의 불일치를 검사합니다. 이전 확정 기록 형식도 읽을 수 있습니다.

## 실제 모델 및 연결 검증

- 기존 김천 1페이지 PDF와 수원 3페이지 PDF를 실제 PaddleOCR·로컬 Qwen3.5-4B로 읽었습니다. 실제 모델 응답·이미지 수·모델 정체성·입력 SHA-256은 `../pdf-compact-values-verification-2026-10-29/`에 보존돼 있습니다.
- 이 폴더의 JSON은 그 실제 OCR·LLM 응답을 최종 정리 코드로 재처리한 결과입니다. 재처리 단계에서 OCR·LLM을 다시 실행하지 않았으며 `postprocessing_replay`에 원래 실행 기록과 최종 코드 해시를 남겼습니다.
- 김천은 장소 3개를 포함한 9개 조건, 수원은 복합 조건을 유지한 16개 조건입니다. 명시적 기준표의 모든 행 ID가 결과에 포함되는지 검사했습니다. 행 ID 포함이 문구의 의미 정확도나 완전성을 보증하지는 않습니다.
- 실제 반환값을 프런트엔드의 PDF 합치기 → 항목 준비 → 기준 확정 함수에 전달했고, 모든 기대값·수준·설명이 스냅샷에 보존됨을 확인했습니다.
- 수원의 새 기준을 격리 API에 제출하고 이전 검수의 포스터 OCR 30개를 재사용해 비교까지 확인했습니다. 결과는 6개 충족·10개 확인 필요이며, 새 포스터 OCR·시각 모델 추론은 실행하지 않았습니다. 기존 검수와 내보내기는 수정하지 않았습니다.
- 백엔드 기본 테스트 789개 및 7개 subtest 통과, DB 통합·외부 실모델 테스트 1334개 제외. 프런트엔드 24개 테스트 및 빌드 통과.

## 남은 확인

짧은 형식이 OCR 오독이나 이미지 시각 모델 미연결을 해결하지는 않습니다. 이번 실제 응답에서도 수원 상단 로고의 `VISIT`을 `VIST`로, 김천 안내 문구의 느낌표를 누락해 반환한 사례가 있습니다. PDF 이미지와 조건을 대조하고 확정해야 합니다. 이 검증은 출력 형식과 전달 경로의 검사이며 모델 정확도 평가가 아닙니다.

앱에 적용하려면 서버를 재시작하고 브라우저 새로고침 후 PDF를 다시 불러와 새 기준을 확정합니다. 텍스트 파일은 짧은 입력 표시를 검토하기 위한 예시입니다. 앱에서 PDF를 다시 불러오면 상세 기준과 원문 근거도 함께 전달됩니다.
