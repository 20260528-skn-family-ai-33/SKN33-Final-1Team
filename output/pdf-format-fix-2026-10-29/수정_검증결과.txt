PDF 카드형 명세서·본문 누락 검사 수정 결과
2026-10-29

적용 상태
수정 완료. 로컬 앱 서버를 재시작했으며 http://127.0.0.1:8000 에 반영했다. 브라우저를 새로고침하고 요구사항 PDF를 다시 불러오면 수정된 추출을 사용한다. 이전 확정 기준이나 검수 기록은 자동 변경하지 않는다.

수정 내용
- 표와 카드형 조건을 공통 구조로 정리한다. 긴 ID, 헤더/본문 분리, OCR이 항목명·ID·본문을 한 문단에 섞은 카드도 연결한다.
- 문서 ID/버전 표지를 조건 ID로 오인하지 않는다. 버전·출처가 모델 출력에 다시 들어와도 실제 요구값과 대조해 분리한다.
- 명시된 절 제목의 수준을 카드에 연결하고 해당 제목 원문도 출처에 남긴다. 앞 절의 수준을 파일 기준에 전파하지 않는다.
- 문구 판정/비교 원칙은 관련 정보 항목의 상세 기준으로 보존한다. 이 규칙에 독립 조건이 없다는 이유로 전체 추출을 실패시키지 않는다.
- 작성 근거/자료 구분/검토 절차를 보완 조건에서 제외한다. 보완 호출에는 실제 조건 문단도 함께 전달한다.
- 확인 메모는 문서 메모로 유지한다. NEW114 회차 충돌은 완료 안내에 표시하고 별도 필수 조건으로 추가하지 않는다.
- 전시명, 시작일·종료일, 기념식·박람회 시간, 참여 대상·참가비, 원본 가로·세로를 정보 항목으로 연결한다. 짧은 기대값과 파일 메타데이터 비교 형식을 유지한다.
- 실제 ID 누락, 카드 본문 연결 실패, 실제 지시문 누락, 근거 없는 출력 및 수준 충돌의 오류 검사는 유지한다.

검증 구분
1. verified/: 다섯 PDF의 실제 PaddleOCR + 로컬 Qwen3.5-4B 추론. 실제 페이지 이미지와 OCR, 모델 원시 응답, 모델·코드 해시, 입력 PDF 해시를 기록했다.
2. replay-current-code/: 실제 추론에서 저장한 OCR/모델 응답으로 최종 후처리를 재현했다. PDF를 다시 렌더링하고 입력 근거·페이지·JSON 스키마·이미지 바이트 길이가 실제 호출과 같음을 검사했다. 이 단계의 처리 시간은 새 모델 추론 시간이 아니다.
3. verified-brief-final/: 문서 버전 출력 분리를 보완한 뒤 기존 브리프를 실제 모델로 재실행했다. 15개 조건 추출을 확인했다.
4. browser-extraction.json / browser-check.json: 재시작한 실제 앱에서 NEW114 원본 PDF 업로드 → 실제 worker 추론 → 진행률 100% → 8개 입력 반영 → 기준 확정을 확인했다. 모의 추론을 사용하지 않았다.
5. acceptance-checks.json: 모든 카드/표 ID, 유형, 파일 규격, 시작/종료일, 시간 구분, 공통 규칙과 충돌 메모, 원본 해시 및 확정 스키마를 대조했다.

범위와 한계
이번 다섯 문서는 PDF 조건 추출의 회귀 사례다. 일반 문서 정확도나 사람 승인 정답을 뜻하지 않는다. UI 확인용 이미지로 PDF 페이지 렌더를 사용했고 포스터 검수는 실행하지 않았다. 실제 모델의 조건은 사람이 확인할 초안 상태다. 출력 문구·예외의 의미 정확도를 모든 문서에서 보증하는 기능은 아니다.
