화면 상태

정상로딩·대기빈 화면오류·예외
허용된 발주와 실제 접수 파일만 표시. 정상 접수와 문서 추출 완료는 각각의 상태로 표시한다.파일별 접수·검증·파싱·추출 단계를 구분하고 처리 중 중복 등록 상태를 안내한다.등록된 발주 또는 파일이 없다고 표시하고 최초 등록 경로를 안내한다. 샘플 기준을 실제 추출 결과로 채우지 않는다.미지원·손상·형식 위장·자원 상한 초과·파싱 실패를 파일별로 구분한다. 실패 문서에서 조건을 만들어내지 않는다.

PDF 보강: 접근·목록 (CC S01, S02)

  • PDF 보강 초대는 조직·발주·역할·만료·수신 계정에 결합하고 로그인 후 재검증. 만료·취소·다른 계정의 초대는 접근을 거절하고, 링크만 가진 익명 사용자에게 계약·파일을 공개하지 않음.
  • PDF 보강 목록은 이름·발주 ID 검색과 담당자·업무 상태·기한 필터를 제공하고 보완 대기·재검수 필요·내 승인 요청을 구분. 검색 결과 없음과 접근 가능한 발주 없음은 서로 다른 안내, 조회 오류를 빈 목록으로 표시하지 않음.

공통 화면 규칙

  • 기준·자료·보고서·run 버전을 상단과 근거 상세에 함께 표시한다. 구버전 결과에는 과거 결과 표시를 유지한다.
  • 버튼을 비활성화할 때 이유와 해결할 항목을 바로 보여 준다. 입력 오류는 해당 필드와 연결하고 입력 내용을 보존한다.
  • 색상과 아이콘에만 의존하지 않고 충족·미충족·확인 필요·미실행·실패를 텍스트로 표시한다. 키보드로 탭·버튼·근거 이동이 가능하게 설계한다.
  • 검수 담당자·제작자·운영/평가 권한은 제안 역할이며 계정·조직·발주 범위를 서버에서 확인한다. UI에서 숨기는 처리만으로 접근 제어를 구현하지 않는다.
  • 유사도는 계산 방법·버전·대상 영역을 함께 표시하며 법적 침해 확률로 표현하지 않는다. AI 출처·기여 비율·게시 승인을 근거 없이 확정하지 않는다.
