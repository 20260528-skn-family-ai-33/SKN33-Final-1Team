## 운영 검증에서 남길 기록

- **릴리스와 시연** — 프론트 SHA·산출물 해시, 8012/8016/8018 API와 포스터 워커의 이미지 digest·`runtime_sha256`·`configuration_sha256`, 8013 영상 API와 OCR·로고 워커 버전, DB 스키마, CloudFront Function과 원본 정책 버전을 기록한다. [구축 설정의 경로](AWS_구축_설정_인수인계_20261110.md#11-cloudfront와-https-경로-설정)로 새로고침·로그인·신규 API·Range 재생을 확인한 뒤, 같은 버전에서 정상 검수, 확정 위반, 근거 부족과 수정본을 시연한다. 각 결과에 실행 ID와 승인 여부를 남긴다.
- **장애와 복원** — 격리 환경에서 대기 취소와 선점 경쟁, 선점 후 취소 거절, 응답 유실·늦은 결과, 워커 재시작을 확인한다. EFS가 없는 상태에서 원본 쓰기를 받지 않는지와 터널 재연결 후 작업 상태를 확인한다. 같은 시점의 RDS와 EFS 백업을 독립 대상에 복원해 원본·보고서 해시, 프로젝트 접근권한, 기준·부모 실행·승인 ID, 영상 JSON과 파일을 대조한다. 원장으로 Neo4j를 다시 만들면 revision과 관계를 확인한다. [복구 가이드](Neo4j_프로젝트_자동복구_가이드.md)
- **혼합 부하** — 서로 다른 계정·문서로 포스터 A02·포스터 검수, 영상 두 슬롯, 로고 대조를 겹쳐 실행한다. 접수·대기·종료 시각, 상태, 결과 접근권한, CPU·메모리, EFS 임시 공간, GPU 메모리와 작업 거부의 사유를 기록한다.
- **독립 평가** — 개발에 사용한 사례와 평가 입력을 나누고, 별도 검토자가 문서 원문·위치, 기대 기준, 포스터/영상 정답과 근거를 기록한다. 누락과 오추출은 전체 정답·전체 추출 항목 수를 각각 분모로, 오통과·오위반·확인 필요는 정답 상태별 항목 수를 분모로 삼는다. 입력과 정답 SHA, 코드·모델·프롬프트 버전, 표본 시각, 처리시간과 실패 사례를 실행별로 남긴다.
- **운영 종료** — 두 기록의 날짜 중 확정된 종료 일시와 담당자를 남긴다. 스토리지·DB·모델과 시연 산출물의 보존 위치·기간, 읽기와 복원 검증 결과, EC2·EFS·RDS·S3·CloudFront·네트워크·RunPod의 유지·종료 여부와 확인 시점의 비용을 기록한다.

## 로컬 검증 결과

- Python 테스트 370개 통과. 실제 PostgreSQL이 필요한 포스터 브라우저 통합 시험 1개는 제외했다.
- 프론트 단위 테스트 118개와 Edge 브라우저 시나리오 15개 통과. 브라우저는 합성 API를 사용했다. Vite 빌드를 별도 임시 폴더에서 확인했다.

## 격리 DB 시험

Docker Linux 런타임에서 저장소의 격리 실행기를 사용한다. 후속 영상 승인 통합은 격리된 PostgreSQL 17.11·Neo4j 5.26.33으로 실행했다. Windows 호스트의 PostgreSQL 18과 기존 데이터는 보존했다.

프레임워크 DB 통합 실행에서 기존 162개가 통과했고 3개를 건너뛰었다. 신규 영상 테스트의 최초 실행은 권한 검사에서 소유자 세션이 교체되어 실패했다. 시험 계정의 세션을 분리한 뒤 신규 테스트를 별도 격리 환경에서 다시 실행해 통과했다. 관련 회귀 테스트 124개도 통과했다.

```powershell
python scripts/framework_graph_test.py -- tests/agent_framework/test_graph_postgres_integration.py tests/agent_framework/test_my_tasks_postgres_integration.py tests/agent_framework/test_front_v2_poster_integration.py -q
```

백업·복구의 자동 시험은 PostgreSQL 17의 `pg_dump`와 `pg_restore`, [테스트 전용 DB 설정](../environment.md)을 갖춘 별도 환경에서 실행한다.

```powershell
uv run pytest -m db_integration tests/app/test_backup_integration.py -q
```
