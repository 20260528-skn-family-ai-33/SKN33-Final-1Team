## 충돌 해결 기준

11개 파일의 충돌을 해결했다. CI 2개, 공통 계약·PostgreSQL 명령·A06 판정 3개, 프레임워크 README·흐름도/소스 HTML·데이터·빌드 기록 5개, 계약 내보내기 스크립트 1개다.

- main의 계약 **3.0.0**, A06 관측 상태·단위·항목별 판정 근거를 유지했다.
- A02의 PDF·자유 입력 의미 구조화, 화면용 문단, 기준 수정·승인·PostgreSQL 저장 흐름을 보존했다. front-v2와 회원가입도 유지했다.
- main의 A04·A05 어댑터, A07 보고, A01·A08 및 개발용 in-memory MCP 코드를 포함했다. 이것만으로 모든 실제 모델이 연결되었다는 뜻은 아니다.
- A06에서 빈 기대값·불명확한 관측은 자동 통과시키지 않는다. A02의 날짜·정규화·부가 조건·시각/파일 속성도 지원 범위를 벗어나면 review로 남긴다.
- 환경 통합은 main의 역할별 설정 전달을 따르며, 기존 A02 인증키는 framework worker에만 전달한다.
- 공개 worker 설정·계약 JSON·스키마와 흐름도/소스 HTML을 새 계약에 맞춰 재생성했다.
- 과거 2.0.0 합성/녹화 fixture는 원문을 보존했다. 테스트 전용 사본의 버전 표시만 현재 계약으로 맞췄으며, 운영 데이터 자동 이관 기능은 추가하지 않았다.
