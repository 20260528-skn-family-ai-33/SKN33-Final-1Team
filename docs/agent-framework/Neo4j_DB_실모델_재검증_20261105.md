## A01·A08 실패 원인

서버의 응답은 다음과 같다.

```text

```

현재 A02 서버 시작 구성은 텍스트 추출용이며 자동 도구 호출 설정이 없다. A01·A08이 보내는 `tools`와 `tool_choice=auto` 요청이 추론 전에 거절된다. 모델의 판단 정확도 실패나 로컬 API·worker 종료로 분류하지 않는다.
