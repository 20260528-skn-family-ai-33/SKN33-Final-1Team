## 별첨 1. 문구·일정 요구사항 후보

### CON-T01

단체명 ‘수원시립교향악단’과 공연 회차 ‘제303회 정기연주회’를 모두 표기한다.

- 허용·검토: 줄바꿈·공백 차이는 허용하되 회차 숫자는 바꾸지 않는다.
- 관찰 출처: 포스터 문구 “수원시립교향악단 / 제303회 정기연주회”

### CON-T02

주요 작품 표기로 ‘H.Berlioz’와 ‘Symphonie fantastique’를 포함한다.

- 허용·검토: 영문 대소문자·단어 사이 공백·줄바꿈은 허용한다. 고유명·작품명 철자는 유지한다.
- 관찰 출처: 포스터 문구 “H.Berlioz / Symphonie fantastique”

### CON-T03

공연 일시는 2026년 4월 29일 수요일 19시 30분으로 표기한다.

- 허용·검토: 수요일/wed, 날짜 구분자와 0 표기는 허용한다. 날짜와 시각을 변경하지 않는다.
- 관찰 출처: 포스터 문구 “2026. 4. 29. wed 19:30”

### CON-T04

공연장은 ‘수원SK아트리움 대공연장’으로 표기한다.

- 허용·검토: 줄바꿈·공백 차이는 허용한다.
- 관찰 출처: 포스터 문구 “수원SK아트리움 대공연장”

### CON-T05

출연자와 역할을 ‘지휘 최희준’, ‘첼로 정우찬’으로 각각 표기한다.

- 허용·검토: 두 사람의 이름과 역할 연결을 유지한다. 인물 사진만으로 이름을 추정하지 않는다.
- 관찰 출처: 포스터 문구 “지휘 최희준 / 첼로 정우찬”

### CON-T06

프로그램에 생상스 ‘첼로 협주곡 1번’과 베를리오즈 ‘환상 교향곡’을 포함한다.

- 허용·검토: 줄바꿈·공백 차이는 허용한다. 외국어 부제 전체와 작품 번호의 세부 표기 요구는 후속 확인한다.
- 관찰 출처: 포스터 문구 “생상스 첼로 협주곡 1번 / 베를리오즈 환상 교향곡”

## 별첨 2. 시각 요소 후보

- **CON-V01** 산 풍경 배경과 출연자 인물 사진 두 점을 포함한다. 이미지 근거와 사람 확인. 사진만으로 인물 신원이나 초상 이용 허락을 확정하지 않는다.
- **CON-V02** 보라색 계열 배경 위에 주요 작품명과 공연 일시가 구분되어 읽히도록 구성한다. 정성 검토. 가독성 합격을 임의의 점수로 자동 확정하지 않는다.

## 개발용 파일 규격 제안

JPEG, RGB, 4500×4500px. 원본 파일 메타데이터를 테스트 규격 후보로 제안한 것이며 원래 발주 조건을 확보한 것은 아니다. 인쇄·편집 원본 규격은 미정이다.

## 변경·승인·출처

표준계약서 6쪽 제5조, 7쪽 제6조·제7조, 11쪽 제19조의 구조를 참고했다. 포스터 문구·시각·파일 조건은 AI가 관찰하여 역작성한 가상 제안이다. 기준 승인 전 초안이며 변경된 문서·포스터에 승인을 자동 승계하지 않는다.

실제 계약·사람 확정 정답·독립 평가셋이 아니다. 이미지 검수 정답을 pass로 미리 지정하지 않았다.
