# A02·DB 샘플 기반 작업 순서

사용자 요청: 설명 없는 단독 **`1`** 입력은 다음 단계 한 개를 진행한다. 현재 단계가 끝나지 않았으면 먼저 마무리한다. 단계 진행 신호는 실제 검수 기준에 대한 사람 승인 기록과 구분한다.

[진행 기록](진행현황.json) · [1단계 시나리오](01_시나리오_설계.md) · [열람 페이지](index.html)

| 단계 | 작업 | 범위 | 상태 |
|---|---|---|---|
| 1 | 시나리오·요구사항 설정 | 기존 3종의 문구·시각·파일 조건과 의도적 보완 항목 1개씩 설계 | complete |
| 2 | 클라이언트 제출용 PDF 작성 | 설정한 시나리오로 개발용 가상 의뢰서 PDF·수정용 MD 작성 | complete |
| 3 | 추출 결과 검토표 준비 | PDF별 조건·기대값·페이지·인용·보완 예상 결과를 별도 정리 | complete |
| 4 | PDF 등록·PostgreSQL 연결 | 기존 파일 저장소 재사용, 문서 버전·해시·프로젝트 접근 연결 | complete |
| 5 | A02 조건 추출 연결 | 모의 응답과 실제 Qwen 실행을 구분하여 추출·출처 검증·저장 연결 | complete |
| 6 | 보완·승인·재조회 연결 | 사람 보완의 출처·기준 버전·승인 기록과 재시작 후 조회 검증 | complete |
| 7 | 포스터 검수·재검수 시험 | 승인 기준에 맞춘 정상/날짜 오류/필수 문구 누락 사례로 관통 확인 | complete |

다음 단계: **전체 단계 완료**.

Qwen 모의 응답과 실모델 결과를 구분한다. 현재 진행 기록은 모델 호출·운영 DB 적용·사람의 기준 승인이 완료됐다는 의미가 아니다.
