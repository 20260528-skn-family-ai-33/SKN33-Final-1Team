# 전시 포스터 제작 의뢰서

수원의 영화, 수원의 극장

기존 포스터를 참고하여 작성한 개발용 가상 의뢰서입니다. 실제 기관이나 인물의 발주·승인 사실을 나타내지 않습니다.

- 문서 식별: EXH-NEW004 / client-draft-v0.2
- 과업 분야: 시각디자인 / 디지털 홍보 포스터
- 결과물: 아래 요구사항을 반영한 디지털 포스터 파일 1점

## 1. 제작 목적

전시의 주제와 개막일, 관람 장소가 명확하게 전달되는 디지털 홍보 포스터를 의뢰합니다. 옛 극장과 영화 자료의 분위기를 살리되 제목과 안내 정보를 구분해 주세요.

## 2. 포스터에 표기할 내용

- 전시명에 ‘수원의 영화’와 ‘수원의 극장’을 모두 표기한다.
  - 허용 범위: 줄바꿈·공백·두 구절 사이의 쉼표 차이는 허용하되 두 구절을 누락하지 않는다.
- 전시 연도는 2026년으로 표기한다.
  - 허용 범위: 2026 또는 다른 연도 정보와 함께 해석 가능한 ‘26년’ 표기를 허용한다.
- 개막일은 2026년 5월 14일로, 요일은 목요일로 표기한다.
  - 허용 범위: 날짜 구분자와 앞자리 0의 차이는 허용한다. 연도·월·일·요일 의미는 동일해야 한다.
- 전시 장소는 ‘열린문화공간 후소 전시실’로 표기한다.
  - 허용 범위: 장소명 내 줄바꿈·공백 차이는 허용한다.

## 3. 시각 구성

- 옛 극장 건물과 영화 관련 자료를 결합한 사진 콜라주를 주요 시각 요소로 사용한다.
- 청록색 바탕, 흰색 주요 제목, 주황색 강조선의 조합을 유지한다.

색감·구성·가독성은 시안에서 함께 확인합니다. 특정 색상 코드나 정량 점수를 지정한 조건은 아닙니다.

## 4. 디지털 납품 규격

- 파일 형식: JPEG (.jpg 또는 .jpeg)
- 픽셀 크기: 가로 3000픽셀 × 세로 3000픽셀
- 색상 모드: RGB

## 5. 담당자 확인 후 반영할 필수 사항

관람시간은 확인 중입니다. 관람 가능한 요일·시작 시각·종료 시각과 휴관일 안내가 필요합니다. 구체적인 내용은 담당자 회신 후 반영해 주세요.

위 필수 사항의 회신을 받은 뒤 표기 내용을 확정합니다. 확인되지 않은 값은 임의로 정하지 말고 담당자에게 문의해 주세요.

## 6. 협의 및 확인 범위

행사에 표시할 정보와 계약상 납품기한은 구분합니다. 실제 계약 당사자·대금·지급 일정·수정 횟수는 별도 협의할 업무 정보이며 포스터 표시 요청에 포함하지 않습니다.

사진·인물·기관 표장·글꼴 등의 사용권과 편집 원본·인쇄물 납품 범위는 별도 자료로 확인합니다. 이 문서는 권리 보유나 사용 허락을 확정한 문서가 아닙니다.

변경 내용은 새 문서 버전으로 기록하고 담당자와 표기 기준을 확인합니다. 이전 초안의 확인 기록을 변경된 기준의 승인으로 사용하지 않습니다.
