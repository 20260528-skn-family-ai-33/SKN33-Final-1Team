## 1. 제작 목적

교향악단 정기연주회의 작품명, 공연 일시·장소와 출연 정보를 알리는 디지털 홍보 포스터를 의뢰합니다. 한글 정보와 외국어 작품명을 함께 읽을 수 있도록 구성해 주세요.

## 2. 포스터에 표기할 내용

- 단체명 ‘수원시립교향악단’과 공연 회차 ‘제303회 정기연주회’를 모두 표기한다.
  - 허용 범위: 줄바꿈·공백 차이는 허용하되 회차 숫자는 바꾸지 않는다.
- 주요 작품 표기로 ‘H.Berlioz’와 ‘Symphonie fantastique’를 포함한다.
  - 허용 범위: 영문 대소문자·단어 사이 공백·줄바꿈은 허용한다. 고유명·작품명 철자는 유지한다.
- 공연 일시는 2026년 4월 29일 수요일 19시 30분으로 표기한다.
  - 허용 범위: 수요일/wed, 날짜 구분자와 0 표기는 허용한다. 날짜와 시각을 변경하지 않는다.
- 공연장은 ‘수원SK아트리움 대공연장’으로 표기한다.
  - 허용 범위: 줄바꿈·공백 차이는 허용한다.
- 출연자와 역할을 ‘지휘 최희준’, ‘첼로 정우찬’으로 각각 표기한다.
  - 허용 범위: 두 사람의 이름과 역할 연결을 유지한다. 인물 사진만으로 이름을 추정하지 않는다.
- 프로그램에 생상스 ‘첼로 협주곡 1번’과 베를리오즈 ‘환상 교향곡’을 포함한다.
  - 허용 범위: 줄바꿈·공백 차이는 허용한다. 이 항목의 필수 표기는 한글 프로그램명과 작곡가명이며, 영문 부제 전체와 작품 번호는 이번 요청 범위에 포함하지 않는다.

## 3. 시각 구성

- 산 풍경 배경과 출연자 인물 사진 두 점을 포함한다.
- 보라색 계열 배경 위에 주요 작품명과 공연 일시가 구분되어 읽히도록 구성한다.

색감·구성·가독성은 시안에서 함께 확인합니다. 특정 색상 코드나 정량 점수를 지정한 조건은 아닙니다.

## 4. 디지털 납품 규격

- 파일 형식: JPEG (.jpg 또는 .jpeg)
- 픽셀 크기: 가로 4500픽셀 × 세로 4500픽셀
- 색상 모드: RGB

## 5. 담당자 확인 후 반영할 필수 사항

관람연령은 확인 중입니다. 최소 관람연령을 확인한 뒤 포스터에 안내해야 합니다. 구체적인 연령과 표기 문구는 담당자 회신 후 반영해 주세요.

위 필수 사항의 회신을 받은 뒤 표기 내용을 확정합니다. 확인되지 않은 값은 임의로 정하지 말고 담당자에게 문의해 주세요.

## 6. 협의 및 확인 범위

행사에 표시할 정보와 계약상 납품기한은 구분합니다. 실제 계약 당사자·대금·지급 일정·수정 횟수는 별도 협의할 업무 정보이며 포스터 표시 요청에 포함하지 않습니다.

사진·인물·기관 표장·글꼴 등의 사용권과 편집 원본·인쇄물 납품 범위는 별도 자료로 확인합니다. 이 문서는 권리 보유나 사용 허락을 확정한 문서가 아닙니다.

변경 내용은 새 문서 버전으로 기록하고 담당자와 표기 기준을 확인합니다. 이전 초안의 확인 기록을 변경된 기준의 승인으로 사용하지 않습니다.
