## PDF 구성

각 2쪽의 텍스트 PDF이며 한글 글꼴을 포함한다.

- 1쪽: 의뢰 개요·제작 목적·필수 문구·일시·장소·표기 허용 범위
- 2쪽: 시각 구성·디지털 납품 규격·담당자 확인 중인 필수 사항·업무 협의 범위

관람시간·관람연령·우천 시 운영 안내는 각 의뢰서에서 하나씩 확인 중으로 남겼다. 실제 답변이나 승인 이력을 생성하지 않았다. 계약 당사자·대금·납품기한을 포스터 이미지의 표시 조건으로 취급하지 않는다.

연주회 프로그램의 영문 부제 전체·작품 번호는 이번 필수 표기 범위에 포함하지 않는다고 명시했다. 축제 교통 안내의 허용 표현은 담당자 확인 후 사용할 수 있는 문장으로 정리했다. 이런 의뢰서 작성상 범위 정리는 manifest에 기록했으며 기존 1단계 시나리오·원 포스터를 수정하지 않았다.

## 입력 경계

**A02 입력은 각 사례의 의뢰서 PDF 한 건이다.** 이 열람 HTML·MD·manifest·시나리오 JSON과 기존 참고 포스터는 조건 추출 입력에 함께 넣지 않는다. 특히 다음 3단계에서 만들 검토표·기대 결과는 별도 검토 자료다.

PDF에는 원 포스터 이미지, 사전에 계산한 추출 결과 JSON, 판정 정답, 내부 조건 ID를 넣지 않았다. PDF에 적힌 요구사항과 확인 중인 항목을 근거로 조건을 추출해야 한다. 파일명이 같거나 버전 표기가 같다는 이유만으로 원본을 덮어쓰지 않고 파일 해시와 문서 버전을 함께 관리한다.

모의 추출·실제 Qwen 호출·DB 연결·기준 승인·포스터 판정은 후속 단계다. 이 문서 생성은 해당 기능의 실행 증거가 아니다.

## 파일과 재생성

- `manifest.json`: 문서 경로·버전·해시·페이지 수·미승인 상태. 추출 정답 데이터가 아님
- 각 사례 폴더: PDF·수정용 MD
- `index.html`: 로컬 상대 경로로 연결한 열람 페이지

재생성 도구는 상위 샘플 폴더의 `tools/build_client_requests.py`다. `reportlab`, `pypdf`, `Pillow`와 한글 TrueType 글꼴이 있는 Python 환경에서 사용한다. 열람에는 Python이 필요 없다.

```bash
python tools/build_client_requests.py --font "한글글꼴의 실제 경로.ttf"
```

이 명령은 `docs/poster-baselines/2026-11-03` 폴더에서 실행한다. PDF/MD는 1단계 시나리오 JSON으로 함께 재생성되므로 내용을 바꾸려면 시나리오를 새 버전으로 수정해 문서와 일치시킨다.
