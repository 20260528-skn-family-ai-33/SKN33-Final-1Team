## 1. 제작 목적

탄소중립 행사와 체험·공연 프로그램을 알리는 디지털 홍보 포스터를 의뢰합니다. 주요 제목, 행사 시간·장소, 프로그램과 교통 안내가 구분되도록 구성해 주세요.

## 2. 포스터에 표기할 내용

- 공식 행사명에 ‘2025 탄소중립 한마당 축제’를 표기한다.
  - 허용 범위: 공백·줄바꿈 차이는 허용한다. 연도는 2025로 유지한다.
- 주요 제목 ‘오늘무해!’와 ‘FESTIVAL’을 모두 표기한다.
  - 허용 범위: 줄바꿈·공백과 FESTIVAL 대소문자 차이는 허용한다.
- 행사 일시는 2025년 11월 2일 일요일 12시부터 19시까지로 표기한다.
  - 허용 범위: 날짜 구분자·앞자리 0·시간 범위 구분자 차이는 허용한다. 시작과 종료 시각을 바꾸지 않는다.
- 행사 장소는 ‘고색역 상부공원 일원’으로 표기한다.
  - 허용 범위: 줄바꿈·공백 차이는 허용한다.
- 프로그램명 ‘탄소중립 그린도시 기념식’을 포함한다.
  - 허용 범위: 줄바꿈·공백 차이는 허용한다.
- ‘탄소중립 어린이 직업체험’과 ‘KidZaniaGo!’ 표기를 포함한다.
  - 허용 범위: 영문 대소문자·단어 사이 공백 차이는 허용한다. 상표 사용 허가는 별도 증빙으로 확인한다.
- 프로그램명 ‘탄소공감 버스킹&영화상영회’를 포함한다.
  - 허용 범위: 공백과 &/및의 차이는 허용하되 버스킹과 영화상영회를 모두 남긴다.
- 주차공간이 협소하므로 가급적 대중교통을 이용하라는 안내를 포함한다.
  - 허용 범위: 안내 취지를 유지한 문장 표현은 담당자 확인 후 사용할 수 있다.

## 3. 시각 구성

- 야외 무대·사람·나무가 있는 축제 일러스트를 하단 주요 시각 요소로 배치한다.
- 분홍색 바탕의 제목 영역, 밝은 프로그램 안내 영역, 녹색 계열의 하단 야외 장면을 구분한다.

색감·구성·가독성은 시안에서 함께 확인합니다. 특정 색상 코드나 정량 점수를 지정한 조건은 아닙니다.

## 4. 디지털 납품 규격

- 파일 형식: JPEG (.jpg 또는 .jpeg)
- 픽셀 크기: 가로 2382픽셀 × 세로 3368픽셀
- 색상 모드: RGB

우천 시 운영 안내는 확인 중입니다. 비가 오는 경우의 운영 방침을 포스터에 안내해야 합니다. 방침과 표기 문구는 담당자 회신 후 반영해 주세요.

위 필수 사항의 회신을 받은 뒤 표기 내용을 확정합니다. 확인되지 않은 값은 임의로 정하지 말고 담당자에게 문의해 주세요.

행사에 표시할 정보와 계약상 납품기한은 구분합니다. 실제 계약 당사자·대금·지급 일정·수정 횟수는 별도 협의할 업무 정보이며 포스터 표시 요청에 포함하지 않습니다.
