# 3단계: A02 추출 결과 검토표

[검토표 열람](index.html) · [MD](03_추출_검토표.md) · [JSON](03_추출_검토표.json) · [제출용 PDF](../client-inputs/index.html) · [진행 기록](../진행현황.json)

전시·연주회·축제 의뢰서 PDF 3건을 읽어 **조건 후보 36개, 미정 필수 항목 3개, 범위 구분 메모 13개**를 정리했다. 각 행에 기대값·페이지·원문 인용을 연결했다. PDF를 새로 생성하거나 A02 모델을 실행한 결과가 아니다.

## 이 자료의 상태

- 검토표는 AI가 작성한 **사람 검토 전 초안**이다.
- `human_verified=false`, `criteria_approval_status=unapproved`, `gold_verdict=null`을 유지한다.
- 페이지·인용의 파일 정합성 확인과 사람이 조건의 정확성을 승인하는 절차는 다르다.
- 완성 포스터를 참고한 시나리오의 계보를 유지한다. 실제 발주서나 독립 성능 평가 정답으로 바꾸어 부르지 않는다.
- 이 JSON은 검토용 형식이다. 프레임워크의 실행 계약·실제 모델 출력·승인된 CriteriaDraft라고 표시하지 않는다.

## 입력과 검토 자료의 분리

**A02 입력은 `client-inputs/`에 있는 제출용 PDF 한 건이다.** 이 폴더의 검토표·페이지 텍스트 사본·기대값 JSON과 기존 포스터는 추출 입력에 넣지 않는다. PDF에 있는 정보만으로 추출했는지 대조할 때 사용한다.

행 ID와 36이라는 개수를 모델 출력에 강요하지 않는다. 모델이 의미를 보존한 채 조건을 합치거나 나눌 수 있으므로, 핵심 내용의 포함 여부·기대값·출처·보완 상태를 확인한다. 이 자료만으로 단순 행 일치율을 서비스 정확도라고 보고하지 않는다.

## 무엇을 확인할까

1. **문구·일시·장소:** 기대값과 명시된 표기 허용 범위를 보존했는지 확인한다.
2. **시각 조건:** 조건은 남기되 정성 검토임을 구분한다. 문서에 없는 색상 코드·임계값·확정 통과 결과를 만들지 않는다.
3. **파일 규격:** JPEG, 픽셀 치수, RGB를 텍스트·사진 내용과 다른 파일 속성 검사로 구분한다.
4. **필수 미정:** 전시 관람시간·연주회 관람연령·축제 우천 시 운영 안내의 답변은 없다. 질문·경고·미확정 조건으로 남기고, 답변을 추정하거나 빈 기대값을 자동 통과시키지 않는다.
5. **업무·메타데이터:** 문서 작성일과 버전을 포스터에 들어갈 행사 정보로 바꾸지 않는다. 계약 대금·납기·권리 증빙은 별도 업무/자료 확인으로 보존하고 이미지 픽셀만으로 확정하지 않는다.

## 인용 확인 방식

`source-pages.json`은 실제 제출 PDF의 페이지별 텍스트 사본이다. 파일 원본의 SHA-256, 문서 버전, 사용한 pypdf 버전을 함께 기록했다.

검토표 JSON의 `source.quote`는 해당 페이지에서 추출한 문자열의 **정확한 부분 문자열**이다. 검색 시에는 줄바꿈·공백만 무시하고, 저장한 인용·해시는 원문 줄바꿈을 그대로 유지한다. `start:end`는 Python 문자열 기준의 Unicode 문자 위치이며 UTF-8 바이트 위치가 아니다. 페이지 번호는 1부터 시작한다.

주 요구 문장 외에 표기 허용 범위·회신 후 확정 문구 등 보조 근거도 별도 인용으로 연결했다. 페이지 텍스트 해시·인용 해시·문자 범위는 모두 기계적으로 재확인할 수 있다. 원본 PDF나 추출 도구 버전이 바뀌면 이 연결을 다시 확인해야 한다.

## 이후 사람 검토

모든 행의 검토자·시각·포스터 판정은 비어 있다. 사람이 검토하면 검토자·시각과 해당 문서 해시를 기록한다. 미정 값에 대한 클라이언트 답변과 원본 추출값은 서로 다른 출처로 보관한다. 단독 `1`이라는 단계 진행 신호는 이 승인을 대신하지 않는다.

## 재생성

상위 샘플 폴더에서 pypdf가 있는 Python으로 실행한다.

```bash
python tools/build_extraction_review.py
```

이 도구는 PDF를 읽고 검토용 HTML·MD·JSON만 작성한다. 제출용 PDF·MD·기존 포스터·모델·DB·기준 승인을 변경하지 않는다. 문서별 해시와 실제 인용을 확인하고 진행 기록은 별도로 검증 후 갱신한다.
