# OCR 개선 전 기준선 — 2026-10-13

기존 EasyOCR로 포스터 5장에 전처리 3종을 적용한 **15회 실제 로컬 추론이 모두 성공**했다. 그러나 행사 정보 추출은 세 방식 모두 초안의 가시 필드 19개 중 1개만 완전히 일치했다. 단순 확대·회색조 변경만으로는 여러 줄 제목, 날짜 표현, 장식 글꼴 문제가 해결되지 않았다.

이 문서는 개선 전 기록이다. 현재 라벨 5개는 AI가 이미지로 작성한 미승인 초안이며 확정 정답이 아니다. 아래 숫자는 초안과의 진단 일치 결과이고, 일반적인 OCR 정확도나 개선 완료를 의미하지 않는다. 운영 OCR·검수 규칙·화면은 이번 기준선 작업으로 변경하지 않았다.

## 잘못된 통과와 불충족 사례

각 포스터의 초안에서 진단용 검수 기준 총 17개를 별도로 작성했다. 기존 웹에서 사용자가 저장한 기준을 변경한 것은 아니다. 정상 문구 기준 14개, 고의로 틀린 장소 문구 기준 1개, 시각 확인 기준 2개다.

| 입력 | 올바른 통과 / 정상 기준 | 잘못된 통과 / 위반 기준 | 확인 필요 / 전체 |
|---|---:|---:|---:|
| RGB 2배 | 1/14 | 1/1 | 13/17 |
| RGB 원래 크기 | 1/14 | 1/1 | 14/17 |
| 회색조 2배 | 1/14 | 1/1 | 14/17 |

김천 이미지에는 초안상 `친환경생태공원`이 보이는데, OCR은 높은 confidence로 `친환경생대공원`이라고 읽었다. 이를 검증하려고 **틀린 문구인 `장소: 친환경생대공원`**을 기준으로 넣었고 세 방식 모두 `pass`를 반환했다. `장소: 친환경생태공원` 기준은 `review`였다. 낮은 confidence만 재인식 조건으로 삼으면 이 문제를 놓칠 수 있다. 위반 기준이 하나뿐이므로 1/1을 일반적인 오통과율로 해석하지 않는다.

RGB 2배에서는 춘천·단양의 올바른 전체 행사명을 요구했을 때, 제목 일부만 추출한 값과 비교해 두 건 모두 `fail`로 판정했다. 제목 조각을 전체 행사명으로 확정하는 문제도 회귀 검증에 포함해야 한다. 로고·잘림 두 시각 기준은 모든 방식에서 `review`를 유지했다.

## 다음 구현 우선순위

1. 근거 ID·좌표를 보존하면서 여러 줄 제목·연도·날짜·장소를 결합한다. 제목 일부만으로 전체 행사명의 불일치를 확정하지 않도록 검증한다.
2. 자동 탐지 영역을 기준으로 횟수·시간을 제한한 재인식을 추가한다. 낮은 confidence, 필수 필드 미추출, 기준 불일치, 후보 충돌을 조건으로 비교한다.
3. 같은 입력·라벨 스냅샷으로 EasyOCR 재인식 설정, 분리된 PaddleOCR 환경, Qwen 4B를 비교한다. 정답 문자·파일명·라벨 좌표를 추론에 전달하지 않는다.
4. 라벨을 사람이 확인하고 사례를 보강한 뒤 설정을 고정해 최종용 입력을 평가한다. 실제 정보 누락·다중 행사·회전 등 아직 부족한 사례를 추가한다.

새 모델 설치·추론, 자동 영역 재인식, 운영 OCR 경로 변경은 아직 진행하지 않았다. 이번 완료 범위는 **재현 가능한 비교 도구와 기존 성능의 첫 실측**이다.
