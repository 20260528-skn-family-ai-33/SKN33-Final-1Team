# C11 — UI와 API 검증 대응표

작성일: 2026-10-18. [구현 기록](구현_C11_React와서버상태연결.md) · [실행 증거](verification/2026-10-18-implementation-C11.json).

실제 Chrome을 사용한 **합성 API UI 시험**과 Node 계약 시험이다. 서버가 실행한 SQL·인증·OCR·파일 저장을 이번에 검증했다는 뜻은 아니다. 백엔드 회귀 592개·하위 7개를 실행했으며 C10의 DB/API 1,265개는 이번에 재실행하지 않았다. 이전 단계의 증거와 이번 시험을 합쳐 새 통합 E2E 통과로 부르지 않는다.

신규 단위 35개와 신규 브라우저 14개는 **49개의 실행 사례**이며 위 설계 ID 수나 백엔드 통합 사례 수가 아니다. 반복 진단 실행/캡처만을 위한 재실행은 사례 수에 더하지 않는다. 자동 판정·수입 원문·미확인 상태를 사람 승인이나 학습 라벨로 승격하지 않는다.
