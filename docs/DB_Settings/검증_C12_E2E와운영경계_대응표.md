# C12 — E2E와 운영 경계 대응표

작성일: 2026-10-18. [구현 기록](구현_C12_실제E2E와프록시검증.md) · [최종 증거](verification/2026-10-18-implementation-C12.json).

C12의 신규 통합 사례 네 개는 실제 브라우저·API·DB·파일을 사용한다. 직접/Vite의 OCR만 합성 어댑터이고, 별도 실제 Paddle 사례는 모델/장치까지 실행했다. Linux HTTPS 사례의 모델은 disabled다. 서로 다른 경로의 시험을 합쳐 Linux 모델 배포·worker·운영 공개 완료라고 표시하지 않는다.

| 구현/설계 ID | 이번 증거 | 남은 경계 |
|---|---|---|
| IMPL-01 | macOS v1 pip check·Linux API 이미지 고정 직접 의존성 설치·Chromium revision 기록 | 다른 OS/GPU·전이 의존성 전체 공급망 인증은 별도 |
| IMPL-02/03 | 기존 회귀·명시적 v1 launcher·테스트/앱 환경 분리·빌드 marker 검사 | 시작 시 자동 migration/seed/모델 설치 없음 |
| IMPL-06~10 | 기존 DB/API 1,265 회귀·M008·실제 PostgreSQL 앱 역할과 Linux startup | 독립 worker 인수/lease는 C13 |
| IMPL-12 | 실제 Linux 전용 volume·uid 10001·업로드/저장소 capability 시작 점검 | 전원 장애·복원 훈련은 C14, Windows 운영 인증 아님 |
| IMPL-13 | 실제 직접/Vite 로그인·admin/admin·Host/Origin/Forwarded/X-Forwarded-* 거절 | loopback 개발 프로필로만 허용 |
| IMPL-14 | 실제 Nginx TLS·헤더 allowlist wire probe·Linux API·HTTPS 브라우저 쿠키/CSRF·직접 위조 HTTPS 거부 | 임시 테스트 인증서이며 공인 인증서/공개 DNS·실제 운영 공개 아님 |
| IMPL-15 | 명시적 TEST_DB_*·임의 DB·일상 public/ACL 전후 불변·최종 임시 DB/컨테이너 정리 | 다른 병행 DB 시험과 함께 실행하지 않음 |
| IMPL-16 | 실제 서버의 응답 후 실행·화면 갱신·저장 후 URL 복원·C11 직렬 폴링/abort 회귀 | worker/remote 취소 정책 C13 |
| IMPL-17 | Python 619+7·프런트 53·두 빌드·기존 DB1265·신규 실제 연결4·CI YAML parser | GitHub Actions job은 정의만 추가, 원격 실행 미실행 |
| IMPL-18 | 실제 Paddle CPU·18 OCR/1 항목·입력 2배/표시 좌표·원자적 저장·server export·현재 설정 health | 1포스터 경로 검증. 정확도/CER/SLA·MPS/CUDA/RunPod/운영 Linux 모델은 미실행 |
| IMPL-19/20 | 기존 증거/데이터/launcher 보존 | 백업/복원 C14·운영 전환 C15 |

| API/AUTH/STORE 범위 | 이번 실제 경로에서 확인한 내용 |
|---|---|
| API-01~08 | 실제 v1 meta/UUID·이미지 업로드/등록 이미지 새로고침·초안 편집/revision·기준 확정·커밋 후 응답 유실과 같은 키 복구. SQL로 확정본 1개 확인 |
| API-09~17 | 실제 기준 UUID만 접수·실제 run 완료/전체성·근거/OCR 지연 GET·표시 박스·실제 모델 출력의 1회 좌표 복원. 서버 JSON 다운로드와 manifest |
| API-19~27 | URL 재진입·새로고침 GET만·서버 재시작 후 DB 세션·viewer/비멤버/익명·Origin/CSRF 거절·API/파일 오류의 HTML fallback 차단 |
| API-31~32 | legacy 유지·v1 빌드 marker·명시적 별도 launcher·직접/Vite/HTTPS 인증·변경 요청 |
| AUTH 운영 경계 | 실제 HTTPS 브라우저의 __Host/Secure/HttpOnly/SameSite=Strict/path=/ 쿠키, 개발 로그인 숨김/비활성, 외부 Origin·무 CSRF 거절, 신뢰 proxy IP만 전달 해석 |
| STORE 실행/파일 | 실제 파일·결과/근거·서버 export·재접속. 기존 C09/C10 파일/DB 경합·중단/원자성 회귀도 유지 |
| STORE 후속 | 원격 유료 제출 없음. lease/회수 C13, 수입·GC·백업/복원 C14. 새 E2E 성공을 해당 미실행 사례의 통과로 합산하지 않음 |

C12 신규 31개는 실제 실행 사례 수다. 화면의 버튼 수·위 설계 ID 수·진단 중 반복한 OCR 횟수를 사례 수에 더하지 않는다. C01~C11 증거는 당시 상태를 기록한 불변 자료이며 이번 결과는 별도 C12 JSON에 남긴다.
