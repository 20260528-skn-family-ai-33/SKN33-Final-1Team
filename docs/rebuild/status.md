## 남은 완료 조건

1. **사용자 보류:** 다른 작업이 사용 중인 Pod의 연결 검증은 나중에 별도로 진행한다. 공식 Qwen3.5-4B endpoint에서 포스터·영상 각각 문서 해석부터 수정·재검수·승인까지 확인해야 한다. 단문 응답 성공을 이 완료 조건으로 대신하지 않는다.
2. 실제 S3·RDS·AuraDB에서 파일 조회와 export/purge, 권한·백업 복원을 확인한다. RDS 백업·S3 이전 객체 버전·복제본의 최대 7일 삭제 반영 정책, 비용 알림과 종료 처리는 운영 설정이 필요하다.
3. 구형 소스·실행 스크립트·테스트·설명 자료의 제거 범위를 마무리한다. 새 기본 진입점은 전환했으나 구형 파일을 저장소에서 모두 제거하지 못했다.

새 worktree에서 구형 소스를 일괄 삭제하는 명령이 자동 승인 검토에 의해 거부되어 실행되지 않았다. 도구는 `blocked by policy`만 반환했으며 더 구체적인 이유는 제공하지 않았다. 다른 방식의 일괄 삭제로 우회하지 않았다. 기존 `backend/app`, 구형 JSX·v1 페이지, 연구·과거 테스트는 새 서비스에서 미사용이지만 남아 있으므로 이 Issue를 완료 처리하면 안 된다.

원래 작업 폴더의 `feat/modeltest-runpod` 미커밋 변경·DB·자료는 보존했다. 이 기록의 검증 기준 시점(2026-10-30 14:52 KST)에는 커밋·푸시·PR·배포 전이었다.
