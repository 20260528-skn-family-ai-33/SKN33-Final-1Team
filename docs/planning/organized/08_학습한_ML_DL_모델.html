SECTION 03

입출력과 라벨별 임계값

3.1 공통 입력

포스터 이미지 1장을 EXIF 방향 보정, RGB 변환, 전체 이미지 시야를 유지하는 448×448 letterbox(배경 RGB 128)로 변환한다. ResNet18은 mean=(0.485, 0.456, 0.406), std=(0.229, 0.224, 0.225)로 정규화한다. EG2는 같은 448 RGB 입력 뒤 저장된 processor를 적용한다. 특징 벡터의 L2 정규화와 라벨 순서를 학습 시와 동일하게 유지한다.

3.2 공통 출력과 판정

출력은 각 라벨의 존재 확률과 이진 판정 8개다. LR은 sigmoid(w·feature+b), FT는 sigmoid(Linear(L2(feature)))로 확률을 계산하고, 확률 ≥ 해당 라벨 임계값일 때 있음으로 판정한다. 서로 배타적이지 않으므로 softmax나 단일 최댓값을 사용하지 않는다.

모델은 이미지 내 위치 박스·OCR 문자열·최종 검수 승인 결과를 출력하지 않는다. 학습 데이터의 모름은 손실·지표의 마스크로 쓰였으며 별도 출력 클래스가 아니다. 향후 서비스에서 사람 검토로 보내는 보류 정책은 별도로 정의해야 한다.

복원 및 재현 절차

5.1 기존 결과를 재현할 때의 순서

  1. 모델 파일 SHA256, 기반 revision, 학습·개발·평가 분할과 승인 라벨 해시를 확인한다.
  2. 실행 스냅샷과 같은 환경을 준비하고, 저장된 본체 구조·전처리와 분류층을 복원한다.
  3. 고정 모델은 기반 가중치에 JSON의 라벨별 계수·절편을 결합한다. FT는 동일 wrapper의 state_dict로 .pt 파일을 로드한다. 라벨 순서와 임계값은 동반 선택 파일을 사용한다.
  4. 같은 평가 37장의 알려진 282개 라벨에 대해 확률·이진 판정·지표를 계산한다. 모름 14개는 제외하고 완전 일치율은 모름 없는 27장을 사용한다.
  5. 속도 재측정은 warmup 3회 뒤 batch 1, 3회 반복, MPS 동기화로 수행한다. OCR·로딩·네트워크 시간은 구분한다.

5.2 보존된 학습 실행 진입점

다음은 기존 학습 코드의 실행 형식이다. 문서 작성 중 실행하지 않았다. 재학습 시 기존 run을 덮어쓰지 않는 새 run-id를 사용한다. 동일 시드라도 장치·라이브러리에 따라 학습 수치가 달라질 수 있다.
