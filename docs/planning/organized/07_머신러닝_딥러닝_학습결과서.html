SECTION 01

과제 개요 및 결과 요약

디자인 납품 포스터에서 인물·사물 8종의 존재 여부를 판별하는 다중 라벨 분류 모델을 학습하고, 정확도와 이미지 처리 시간을 비교하였다.

검수 기준의 시각 요소를 자동 점검하기 위한 보조 분류기를 만드는 것이 목적이다. 한 이미지에 여러 요소가 동시에 존재할 수 있어 8개의 이진 출력을 사용했다. 모델의 존재 판별 결과는 추후 OCR·기준 대조와 함께 활용할 수 있으며, 이번 실험에서 계약 준수 여부의 최종 판정까지 평가한 것은 아니다.

2.3 분할·전처리

승인된 group_id 기준의 다중 라벨 그룹 분할을 사용했다. 난수 시드 20261022, 목표 비율 60:20:20으로 분할하고 동일 그룹의 분할 간 중복이 없음을 확인했다. 이번 파인튜닝에서도 기존 이미지 ID와 분할을 유지했다.

입력은 EXIF 방향 보정 → RGB → 전체 시야를 보존하는 448×448 비율 유지 리사이즈·중앙 패딩(RGB 128)이다. ResNet18 정규화와 EG2 processor는 각 구조에 맞게 적용했다. EG2 이미지 토큰 예산은 280이며 오디오 인코더는 로드하지 않았다.

모델 학습 및 선택 방법

승인 라벨 · 그룹 분할 고정→학습셋 학습→개발셋 후보·임계값 선택→체크포인트·설정 고정→평가·속도 측정

3.1 본체 고정 + 머신러닝 분류층

ResNet18의 512차원 특징과 EG2의 768차원 특징을 각각 L2 정규화한 뒤, 라벨별 독립 이진 Logistic Regression을 학습했다. 본체는 고정했다. C ∈ {0.01, 0.1, 1, 10}, class_weight ∈ {balanced, 없음}을 탐색했으며 두 경로 모두 C=10, balanced가 선택됐다. solver는 lbfgs, max_iter는 2,000이다.

3.2 본체 파인튜닝

기존 LR 계수와 절편을 Linear 분류층으로 복사해 초기화하고, 본체와 분류층을 함께 학습했다. 손실은 모름을 제외한 BCEWithLogitsLoss다. 체크포인트는 개발 Macro AP가 가장 높은 epoch에서 저장하고, 후보는 해당 체크포인트의 개발 Macro F1을 우선 비교해 선택했다.

비교 조건

입력 이미지·승인 라벨·분할·평가 방법은 같고, 본체 파인튜닝의 탐색 후보 수와 실제 학습 예산은 다르다. 표는 이번에 실행한 설정을 비교한 결과이며 각 모델의 최대 성능 비교가 아니다.

SECTION 06

결과 분석과 개선 과제

6.1 결과 판단

  • 분류층 학습의 효과: EG2 고정 특징 + LR은 Macro F1 0.7815로 이번 네 경로 중 가장 높았다. 사전학습 본체 전체를 추가 학습해야만 유효한 분류가 가능한 것은 아니었다.
  • ResNet18 파인튜닝: 고정 특징 대비 정확도는 +3.55%p, Macro F1은 +0.0894다. 다만 F1 증가의 약 93%가 평가 양성 4개인 불꽃놀이 항목에서 나왔고, 다른 7개 항목 평균 F1 증가는 약 0.0070이었다.
  • EG2 파인튜닝: 라벨별 정확도는 높아졌지만 Macro F1·완전 일치율은 개선되지 않았다. 포스터 행 단위 paired bootstrap 10,000회의 정확도 차이 95% 구간은 −1.39~+5.00%p, Macro F1 차이는 −0.05668~+0.04841로 모두 0을 포함한다. 고정 EG2 대비 확실한 개선을 결론 내리기 어렵다.
  • 활용 판단: 이번 분류 품질 기준선은 EG2 고정 + LR, 낮은 지연시간이 필요한 비교 후보는 ResNet18 FT로 기록한다. 운영 모델 선정과 90% 달성은 추가 검증 후 결정한다.

6.2 한계와 후속 과제

  1. 187장·단일 분할·AI 보조 초안의 사용자 일괄 승인에 근거한다. 독립 라벨 검토와 새 평가셋을 확보한다.
  2. 평가 37장을 재사용한 회귀 비교다. 새로운 행사·디자인·출처의 데이터로 일반화 성능을 확인한다.
  3. 악기 7개·불꽃놀이 4개 등 양성 표본이 적다. 항목별 누락·오탐을 확인하고 학습 표본을 보강한다.
  4. bootstrap은 포스터 행 재표집이며 그룹 군집·라벨 불확실성·학습 및 모델 선택 불확실성을 포함하지 않는다.
  5. 후속 모델 추천은 별도 실험 후보이며 이번 학습 완료 모델에 포함하지 않는다. PaddleOCR는 유지했으며 이번 시각 분류 실험의 학습 대상이 아니다.
  6. 새 모델 서비스 연동, RunPod 이식, 운영 배포 및 OCR 포함 실제 전체 지연시간 검증은 이번 결과서의 완료 범위에 포함되지 않는다.
SECTION 07

학습 산출물과 근거

모델 파라미터·체크포인트·선택 기록·평가 예측·지연 원자료가 보존되어 있다. 기존 검증 보고서의 ResNet18 1,689개, EG2 3,339개 항목 통과 기록을 확인했다. 이는 저장 산출물의 정합성 검증이며 별도 독립 데이터 평가가 아니다.
