기능 범위·현황

33개 기존 기능 ID를 보존하면서 통합 초안과 2026-10-30 DB 결정에 맞춰 정의를 다시 작성했습니다. 포스터와 숏폼, 세 승인 지점, MCP, PostgreSQL 원천과 Neo4j 관계 조회를 현재 목표로 사용합니다.

표기뜻
필수최종 통합 목표에 포함. 구현 완료 표시는 아님
기반 코드 / 연결 추가소스에서 일부 기능 확인, 전체 업무 연결·수용 검증은 남음

후속 / 필수 경로 제외현재 핵심 통합 이후 별도 채택 근거 필요

기능을 단순히 구현/미구현 두 값으로 집계하지 않습니다. legacy PDF·검수 경로와 별도 PostgreSQL v1 코드가 공존하며, 실제 배포·서비스 통합 상태는 실행 증거로 갱신합니다. 과거 기능 19개 미구현·11개 부분·3개 설계 수치는 최신 진행률로 재사용하지 않습니다.

이 표는 현재 코드 이름과 목표 계약을 정합화한 정의입니다. 영상·관계·승인에 필요한 모든 필드가 이미 DB/API에 구현되어 있다는 뜻은 아닙니다. 새로운 필드·enum·진리표는 샘플 계약과 검증 사례를 함께 고정합니다.

공통 수용 시험

  • 확정 조건 목록의 모든 항목에 검사 결과 또는 실패·미지원·확인 필요를 남긴다.
  • 권한·프로젝트·버전 범위 밖 근거가 조회·파일·화면에 노출되지 않는다.
  • 미승인·취소·기간 경계·매체가 다른 예외를 적용하지 않는다.
  • 원천 변경·반영 중복/역순·Neo4j 장애·복원 이후 정합성을 확인한다.
  • 영상 미관측 구간과 실패 프레임을 표시하고 검증하지 않은 연속 노출은 통과시키지 않는다.
  • 세 승인과 수정본 재검수는 비개발자 브라우저 E2E에서 확인한다.
