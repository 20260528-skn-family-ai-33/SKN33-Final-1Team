상세 기준: 기능정의서 · 현재·목표 실행 계약

1차 사용자는 지자체·축제 주최 기관의 검수 담당자, 디자이너·제작자, 최종 승인자이다. 발주자·전문 검토자·관리자·내부 개발 역할까지 R01–R07로 나눠 목표 행동을 설명한다. 광고 납품물은 2차 확장, 영상·외부 연동은 P2이며 모든 역할 UI가 현재 제공되는 것은 아니다.

현재 실제 업무 역할별 권한은 미구현입니다. localhost용 admin / admin은 개발 시연용 로그인으로, 회원가입·업무 계정·프로젝트 소유권 검증을 대신하지 않습니다. 아래 사용자별 행동·권한·완료 기준은 목표 설계입니다. 원 기능 33개와 요구사항 69개 ID는 보존하고 최신 기획 연결·현재 구현은 하단 추적표에 별도 표시합니다.

현재 가능한 흐름
admin 로그인 → PNG·JPEG·WEBP 이미지 1장과 요구사항 입력 → 항목 편집·선택·기준 확정 → OCR → 충족·위반·확인 필요와 문구·근거 박스·JSON 확인.

React·FastAPI·BackgroundTasks와 로컬 JSON/이미지 저장을 사용합니다. 로컬 기본 OCR은 PaddleOCR 단독(paddle-only)이며 run.sh·run.cmd만 실행합니다. EasyOCR 비교는 OCR_PIPELINE=baseline으로 선택하고 RunPod 기본은 baseline입니다. 현재 다시 실행은 새 검수 ID 생성이며 업무 이력·수정본 연결은 예정입니다.

역할 ID 사용자 유형 정의 핵심 책임

R02 제작자 — 디자이너·납품 담당자 발주에 배정되어 광고 이미지와 제작 증빙을 제출하는 사람 납품, 제작·소재 증빙 제출, 수정본 제출

2. R01 — 일반 사용자 / 발주자

목표 역할: 발주·프로젝트·문서·사용 계획 관리와 역할별 보고서 접근은 예정입니다. 현재 입력의 프로젝트 이름은 업무 발주 등록이 아닙니다.

목적: 광고 제작 요구사항과 실제 사용 계획을 전달하고, 발주 진행 상태와 검수 결과를 확인한다.

기능 사용자 행동 결과 기존 기능
발주 생성·조회 제목, 담당자, 납기, 목적을 입력하고 본인에게 허용된 발주를 조회한다 고유 발주 ID, 상세 정보, 진행 상태 F-01
기준 문서 등록·추출 요청 계약·요구사항 문서를 발주에 등록한다 원문 위치가 연결된 기준 초안과 확인 질문 F-02, F-04
사용 계획 등록·변경 게시 매체, 기간, 지역, 유료 광고 여부, 재가공 범위를 입력한다 버전이 있는 사용 계획과 변경 이력 F-14
기준·보고서 확인 확정 기준, 검사 결과, 근거, 미검사·미해결 항목을 확인한다 현재 버전의 검수 결과와 보고서 F-03 조회, F-09
보고서 다운로드 내보내기 권한이 있는 경우 현재 보고서를 내려받는다 대상 버전과 생성 시각이 포함된 Markdown F-16
진행 조회·요청 입력 진행 상태를 조회하거나 자연어로 상태 조회 등 허용된 업무를 요청한다 실행 상태와 요청 분류 결과 N-02, S-02
외부 전송 승인·철회 전송 승인 권한을 별도로 받은 경우 수신자·목적·파일·범위를 확인한다 허용 범위의 승인 또는 철회 기록 N-01

입력: 발주 정보, 읽을 수 있는 PDF·TXT·MD, 콘텐츠 사용 계획.
출력: 발주 상세, 기준 초안·확정 상태, 진행 상태, 검수 보고서.
권한: 배정된 조직·발주 안에서만 조회·등록하며, 기준 확정·검수 실행·최종 승인은 해당 권한을 별도로 받은 경우에만 가능하다.

완료 기준: 등록한 발주와 문서·사용 계획이 올바르게 연결되고, 조회 결과가 최신 버전과 일치한다. 사용 계획의 미입력·모호한 범위는 추가 질문으로 남는다. 기준 문서 제출과 기준 확정은 별도 상태다.

배정 제안: 원문에서 검수 담당자에게 배정된 발주 등록·기준 문서 제공·사용 계획 입력을 발주자에게도 부여한다. 보고서 내보내기 역시 권한 기반으로 확대하는 제안이다.

3. R02 — 제작자 / 납품 담당자

목표 역할: 제작자 계정·납품 버전·수정 요청 작업함은 예정입니다. 현재 한 장 업로드는 개발용 검수 입력입니다.

목적: 확정된 기준에 맞는 광고 이미지와 제작 증빙을 납품하고, 보완 요청을 처리한다.

기능 사용자 행동 결과 기존 기능
배정 발주·기준 확인 본인에게 배정된 발주의 확정 기준과 필수 자료 목록을 확인한다 현재 기준·납품 요구사항 F-01 조회, F-03 조회
납품·제작 자료 제출 PNG·JPEG, 지원 편집 원본, 작업 이력, AI 신고, 소재 이용 증빙을 제출한다 파일 목록, 접수 여부, 납품 묶음 버전 F-04
검수 결과 확인 본인에게 공유된 결과·지적 영역·근거를 확인한다 수정 대상과 필요한 보완 자료 F-09
보완 작업 처리 내부 작업함에서 담당 작업과 기한·완료 조건을 확인한다 작업 처리 이력 F-10
수정본·추가 증빙 제출 수정 이미지 또는 추가 증빙을 원 요청에 연결해 제출한다 새 입력 버전과 이전 버전 연결 F-04, F-11
처리·재검수 상태 확인 접수·검수·재검수·승인 상태를 확인한다 최신 진행 상태 F-09, N-02

입력: 납품 이미지, 제작 자료, 소재 증빙, AI 사용 신고, 수정본.
출력: 접수 기록, 버전 이력, 보완 작업 처리 상태.
권한: 배정된 발주의 제출·수정본 등록과 허용된 결과 조회. 기준 확정, 본인이 처리한 작업의 검수상 해결 확인, 최종 승인은 해당 역할 권한이 별도로 있어야 한다.

완료 기준: 자료의 종류·대상·버전이 보존되고, 수정본이 원래 보완 요청과 연결된다. 파일 제출, 작업 해결, 최종 승인은 서로 다른 상태로 표시한다. 미지원·손상·확장자 위장·한도 초과는 구분해 안내한다.

4. R03 — 검수 담당자

현재 일부 구현: 요구사항 직접 입력·항목 편집/선택/화면 확정·OCR 실행·결과/근거 확인. 아래 문서 자동 추출·권한·티켓·이력·수정본 연결은 목표 동작입니다.

목적: 기준을 확정하고 검사 결과를 검토하여, 필요한 수정과 재검수를 진행한다.

기능 사용자 행동 결과 기존 기능
발주·자료 관리 담당 발주와 문서·납품·증빙의 접수 상태를 확인한다 검수 대상과 필수 자료 목록 F-01, F-02, F-04, F-14
기준 초안 검토·확정 추출값과 원문을 대조하고 보정값·사유를 기록한 뒤 확정한다 확정자·시각·버전이 있는 기준 F-03
검수 실행·재시도 확정 기준과 납품 버전을 선택해 검사한다. 재개·자동 반복은 설계 범위이며 현재 미구현이다 실행 상태, 검사 결과, 오류·시도 기록 F-05, F-06, F-08, F-15, S-01
제품 원본 비교 제공 제품 원본과 납품 이미지의 차이를 확인한다 변화 후보, 비교 영역과 한계 F-17
외부 후보 검색·비교 전송 승인 범위에서 외부 검색을 요청하고 비교 결과를 확인한다 후보 출처·접근 상태·도구 계산 근거 F-18, F-19, N-01
제작·사용 근거 검토 AI 신고, 작업 이력, 소재 증빙을 사용 계획과 대조한다 누락·불일치·미확인 사항 F-07, F-14
게시 기준·근거 확인 출처·확인일·버전·적용 범위를 확인한 기준을 선택한다 적용 항목별 결과와 관련 근거 F-20, S-04
결과·보고서 검토 항목 판정, 실행 상태, 원문·이미지 영역·근거를 확인한다 검토한 보고서와 미해결 항목 F-09, F-16
보완 요청 확정 AI 초안을 수정하고 담당자·기한·완료 조건을 확정한다 내부 작업함의 보완 작업 F-10
재검수·해결 확인 담당자가 수정 완료를 먼저 확인한 뒤 새 납품물의 확정 조건 전체를 재검수하고, 그 근거로 해결 여부를 확인한다. 변경 영향 분석은 설명·추적에 사용하며 검사 범위를 줄이지 않는다 새 실행 결과, 지적별 해결 기록 F-11

입력: 기준 초안, 원문, 납품 묶음, 증빙, 사용 계획, 이전 결과·보완 요청.
출력: 확정 기준, 검수 보고서, 보완 작업, 재검수 결과와 해결 기록.
권한: 담당 발주의 기준 확정·검수 실행·보완 요청 확정·재검수. 최종 승인은 R05 권한을 별도로 부여받은 경우에만 가능하다.

완료 기준: 필수 충돌이 남으면 기준 확정을 차단한다. 확정된 적용 기준 전체를 검사 대상에 포함하며, 검색 상위 결과만으로 범위를 줄이지 않는다. 정상 실행의 판독 불확실성은 확인 필요, 도구 오류는 항목 실행 실패(execution_status=failed)·미판정(verdict=null)으로 구분한다. 보완 요청은 확인된 근거와 연결하고, 요청 확정자는 사람으로 기록한다.

추가 제안: 권리 관계·계약 해석·공식 근거 적용이 모호한 항목을 R04에게 배정하는 전문 검토 요청 기능. 원문에는 독립된 전문 검토 배정·작업함 기능이 명시되어 있지 않다.

5. R04 — 법률·권리 검토자 · 선택 확장

선택 확장·미구현: 법률·권리 전문 검토와 소재 증빙은 광고 확장 시 검토할 상세 제안입니다. 1차 행사 포스터의 현재 자동 기능이 아닙니다.

선택 확장·미구현. 전문 검토 배정과 L-01 의견 관리의 도입 여부는 별도 범위 결정 대상이다. 기존 33개 기능의 필수 완료 조건이나 확정된 권한으로 집계하지 않는다.
