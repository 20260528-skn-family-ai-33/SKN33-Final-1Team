세 승인·예외·버전

승인사람이 확인할 내용저장·차단할 조건
승인 1 · 기준 확정원문 전체·추출 누락·잘못된 조건·분류/AND/OR·출처criteria_version_id·확정자/시각·원문/조건 스냅샷. 봉인 뒤 수정은 새 버전
승인 2 · 수정 요청 확정위치·현재 상태·요구 수정·판단 근거·대상 제작물요청 버전·원 run·조건/근거 ID·확정자/시각. AI 초안 자동 전송/확정 금지
승인 3 · 최종 승인산출물/기준/결과 버전, 해결 여부·미지원/미관측·예외asset_version_id·criteria_version_id·run_id·승인자/시각. 변경물에 승인 자동 승계 금지

한 사람이 세 지점을 담당할 수 있다는 방향을 유지하되, 역할 겸임·위임·대리 승인·해결되지 않은 항목의 승인 허용 기준은 팀이 결정합니다. 프로젝트 권한명이나 모델 pass로 승인 단계를 생략하지 않습니다.

예외 승인은 아직 허용 여부를 결정해야 합니다. 허용한다면 기계 판정과 별개로 예외 사유·승인자·대상 버전·매체·유효기간·취소·원문 근거를 보존하고 Neo4j에는 그 확정 관계를 투영합니다. 합성 예외 실험의 성공을 실제 예외 승인 업무 완료로 설명하지 않습니다.

제작자 수정본 제출 → 새 버전 → 전체 기준 재검수 → 해결/미해결 검증 → 최종 승인 순서입니다. 기준이 변경된 경우 변경 영향 조회는 재검수 후보를 제공하며 과거 결과·승인을 자동 수정하지 않습니다.
