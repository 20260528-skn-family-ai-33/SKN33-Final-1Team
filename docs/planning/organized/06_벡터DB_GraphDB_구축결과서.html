개요·선택 근거

Neo4j로 기준·예외·출처·변경 영향을 연결하고, Qdrant로 추가 근거 후보를 검색합니다.

확정 기준·권한·버전·실행 결과의 원천은 PostgreSQL입니다. Neo4j 메인은 핵심 관계 조회의 역할을 뜻하며 업무 데이터 원천의 교체를 뜻하지 않습니다.

Neo4j 선택 근거

다른 조회에서는 PostgreSQL이 빨랐지만, 핵심인 변경 영향 추적의 확장 조건에서 평균 22.8%·p95 38.8%의 지연 단축을 확인해 Neo4j를 선택했습니다.

합성 예비 실험의 특정 조건에 한정됩니다. 9개 조건 중 8개는 PostgreSQL 평균이 더 짧았고, 두 DB 모두 기능 정답을 충족했습니다.

팀 내부 설명 메모

PostgreSQL로도 가능한가? 가능합니다. 같은 정답을 두 DB가 모두 반환했습니다. Neo4j 선택은 관계 경로 모델링 목적과 확장 변경 영향 조건의 관측 지연을 근거로 설명합니다.

하이브리드가 검색 품질 1위인가? 이 결과로 그렇게 말할 수 없습니다. 실제 포스터 평가에서는 Dense가 가장 높았습니다. 기본 Hybrid는 Dense + BM25 / RRF 1:1을 가리키며, 운영 정책의 최종 확정과 구분합니다.

951/951이 실제 검수 정확도인가? 합성 정책에 대한 프로그램 정답 일치입니다. 실제 계약 위반 판정, 사람 승인 정확도, 업무 시간 절감 수치로 사용하지 않습니다.

벡터·검색 실측

기본 Hybrid = BGE-M3 Dense + 한국어 BM25 / RRF 1:1

Dense는 문맥 기반 문서 후보를, BM25는 토큰 기반 후보를 찾습니다. 원점수를 직접 더하지 않고 순위로 결합합니다. 1:1은 기본 비교군의 정의이며 전체 과업 최우수 또는 운영 채택 확정을 뜻하지 않습니다.

실제 포스터 252장

카탈로그 식별자가 정답. 평가 140장·280질의이며 예비 52장은 검색 후보에만 포함합니다.

각 80장으로 총 160개 이미지. v1 40쌍 개발, v2 40쌍 평가입니다.

총 412개 이미지
