AND/OR·조건부·예외를 그래프로 옮길 때

제안: PG에 조건식 원본과 개정 이력을 보존하고, 필요하면 ConditionGroup(op=AND|OR)와 순서가 있는 하위 조건을 Neo4j에 투영합니다. 조건부 적용·승인 예외는 각각의 대상·근거·유효기간을 유지합니다. 실제 테이블·라벨·enum은 계약 동결 때 확정합니다.

‘A 또는 B, 단 C 상황은 제외’를 A·B·C 모두 필수인 세 조건으로 바꾸지 않습니다. 그래프의 연결 경로는 조건식의 참·거짓을 대신하지 않습니다. A06 또는 규칙 평가기가 정책 버전과 관측 결과로 식을 평가하며, 누락·판독 불가·미지원·적용 관계 미준비는 별도로 남깁니다. review의 AND/OR 전파·예외 우선순위는 승인된 진리표가 있어야 자동화합니다.

텍스트·시각 엔진과 관측 근거

Qwen 중심, 파서+Qwen, OCR 혼합을 최종 선택한 것으로 바꾸지 않았습니다. 어댑터 출력에는 원문 인식값·정규화값·검사 항목·모델/프롬프트/규칙 버전·오류·지원 여부를 연결합니다. 로고의 정렬 성공·유사도·차이율은 관측 근거이며, 승인 조건의 충족 여부나 사람 승인을 대신하지 않습니다.

Neo4j 선택 근거를 적용하는 범위

간단한 조회에서는 PostgreSQL 평균이 더 짧았지만, 근거 경로·유효 예외·변경 영향이라는 관계 기능을 일관된 모델로 구현하는 방향을 택합니다. 기존 합성 확장 변경 영향 시험에서는 Neo4j가 평균 22.8%·p95 38.8% 짧았고, 다른 8개 조건은 PG 평균이 짧았습니다. 이는 특정 조건의 실험 근거이며 관계 설명 편의·개발 공수·전체 서비스 성능의 실측을 대신하지 않습니다.

깊이·반환량 제한에 닿은 조회는 complete=false 또는 명시적 오류로 반환하는 계약을 제안합니다. 부분 경로나 잘린 영향 목록을 완전한 정답으로 표시하지 않습니다. 현재 권한은 항상 PG에서 확인합니다.
