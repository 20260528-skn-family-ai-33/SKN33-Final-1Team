크리에이티브체커는 창작물·홍보물을 의뢰서·브랜드 가이드·체크리스트와 공식 기준정보에 대조하고, 수정 요청부터 사람의 최종 승인까지 연결하는 검수 업무 자동화 프로젝트입니다.

첫 적용 대상은 행사·축제 포스터입니다. 행사명·일정·장소와 문구를 확인하는 흐름을 먼저 검증하고, 광고 납품물로 확장합니다. 30초 내외의 광고·홍보 영상은 후속 검토 범위입니다.

흩어진 검수 기준

문서와 대화에 나뉜 조건을 모으고, 사람이 확정한 기준 목록을 남겨 누락 여부를 확인합니다.

반복 대조와 수정 전달

판독 문구와 이미지 좌표를 함께 제시해 어떤 조건을 왜 수정해야 하는지 설명합니다.

기준·수정본의 버전 혼동

기준·납품물·검수 실행을 연결하고, 최신 버전을 기준으로 승인하도록 설계합니다.

불확실한 결과의 처리

충족·위반·확인 필요와 실행·증빙 상태를 구분합니다. 판단 근거가 부족한 항목은 사람이 확인합니다.

업무 시간 절감과 누락 감소는 검증할 기획 가설입니다. 사용자 인터뷰와 실제 업무 시간 측정은 아직 수행하지 않았습니다. 현재 구현한 입력·OCR·결과 화면과 전체 업무 자동화 목표를 구분해 설명합니다.

목표 업무 흐름

  1. 등록·접수: 문서와 이미지, 프로젝트 정보를 등록하고 요청을 신규 검수·재검수·기준 변경·상태 조회·기타로 분류합니다.
  2. 기준 추출·사람 확정: 문서의 조건·값·예외·출처를 제안하고, 담당자가 누락과 충돌을 확인해 확정합니다.
  3. 확정 조건 전체 검사: 문구·시각 요소를 검사하고 공식 행사 정보와 대조합니다. RAG는 원문·예외의 근거를 찾으며 검색 상위 일부로 체크리스트를 대체하지 않습니다.
  4. 근거 검증·보고: 항목 누락·충돌·근거 부족을 확인하고 검토 보고서 초안을 작성합니다.
  5. 수정 요청·수정 확인: 사람이 수정 요청을 확정하고 제작자가 새 납품물을 제출합니다. 사람이 수정 완료를 확인합니다.
  6. 새 납품물 전체 재검수: 기존 지적 해결과 새 오류를 함께 검사합니다. 기존 오류 영역만 재검사하는 것으로 완료하지 않습니다.
  7. 사람의 최종 승인: 최신 기준·납품물·실행 버전과 미해결 항목을 확인한 승인자가 결정합니다.
