프로젝트 정의

Creative Checker는 발주서·계약서에서 사람이 승인한 제작 조건을 기준으로 포스터와 숏폼 영상을 검사하고, 근거 확인·수정·재검수·최종 승인까지 연결하는 MCP 기반 다중 에이전트 업무 자동화 서비스를 목표로 합니다.

문서와 산출물 사이의 반복 대조, 빠진 조건 확인, 수정 전달과 버전 혼동을 줄이는 것이 목표입니다. 자동화의 성과는 모델 점수 하나가 아니라 전체 조건 처리·근거 재현·수정 해결·사용자의 승인 흐름으로 검증합니다.

문제제공할 기능성공을 확인할 증거
기준이 문서·표·가이드에 흩어짐조건 초안과 원문 위치를 함께 제시누락·없는 조건 생성·근거 위치 오류, 사람 수정 시간
문구·시각 오류를 반복 확인조건별 관측값·판정·영역/프레임 근거오류 놓침·정상 오차단·사람 확인 비율
수정 요청과 수정본의 연결 부족확정 요청 → 새 버전 → 재검수 연결해결/미해결과 이전 근거를 재현하는 E2E
어느 버전이 승인됐는지 불명확기준·산출물·run에 묶인 최종 승인승인 이후 변경물에 승인이 자동 승계되지 않음

현재 목표 DB는 PostgreSQL + Neo4j입니다. PostgreSQL이 업무 원천·권한·버전·실행·승인을 맡고, Neo4j는 근거·예외·변경 영향 관계 조회를 맡습니다. Qdrant·임베딩 검색은 필수 경로에서 제외합니다. 이 DB 방향은 2026-10-30 사용자 결정이며 팀 최종 승인과 서비스 구현 완료는 별도입니다.

기관·행사 제작물의 발주자, 제작자, 검수자와 승인자가 초기 사용자 후보입니다. 수요·유료 전환·가격은 파일럿에서 확인할 가설로 관리합니다. 측정하지 않은 절감률이나 매출을 확정 효과로 쓰지 않습니다.
