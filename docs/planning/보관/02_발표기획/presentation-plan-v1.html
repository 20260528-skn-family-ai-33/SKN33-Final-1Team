BACKGROUND → PROBLEM 02 / 06

넘쳐나는 창작물,
사람의 검수에 한 번의 확인을 더합니다.

숏츠·인스타그램 릴스·광고 이미지까지,
사람이 만든 창작물과 AI가 생성한 콘텐츠를 검수해야 합니다.
담당자가 검토하더라도 놓칠 수 있는 부분을 AI 검사로 보완합니다.

01 · 검수의 필요성

제작 방식과 관계없이 확인합니다.

사람이 제작하거나 AI가 생성한 콘텐츠 모두 상품명·할인 문구·브랜드·규격이 요청한 조건과 맞는지 살펴야 합니다.
검수 기준은 제작 방식보다 의뢰한 내용에 있습니다.

02 · 사람이 놓칠 수 있는 부분

꼼꼼히 보아도 누락은 생길 수 있습니다.

명세서·계약서·브랜드 가이드의 조건을 여러 납품물·수정본과 반복 대조하다 보면 작은 문구 오류나 변경 사항을 놓칠 수 있습니다.
담당자의 검토를 뒷받침할 추가 확인이 필요합니다.

03 · AI 검사로 보완

놓칠 수 있는 항목을 한 번 더 확인합니다.

문서에서 기준을 추출하고, 사람이 확정한 기준으로 납품물을 검사합니다. 불일치와 확인이 필요한 위치를 근거와 함께 보여 줍니다.
담당자는 AI 검사 결과를 검토해 최종 판단합니다.

해결할 문제: 사람이 놓칠 수 있는 조건·오류를 추가로 검사하고, 근거를 제공해 최종 판단을 돕기

숏츠·릴스는 광고 환경을 설명하는 사례입니다. 1차 구현 대상은 광고 이미지이며 영상 검수는 후속 확장 범위입니다. 실제 업무 부담과 개선 효과는 사례 수집·비교 실험으로 확인합니다.

SOLUTION 03 / 06

기준을 읽고, 검사하고,
수정이 끝날 때까지 연결합니다.

명세서·계약서·브랜드 가이드에서 기준을 추출합니다.
사람이 확정한 기준 전체를 검사하고, 각 결과에 근거를 남깁니다.

문서·납품 등록→기준 추출→사람 확정→검수·검증→수정 요청→재검수→사람 승인
AGENT 01기준 분석

문서에서 조건·출처를 추출하고 모호한 내용을 질문합니다.

AGENT 02납품 검수

OCR·시각 도구를 선택해 항목별 관찰과 근거를 만듭니다.

AGENT 03근거 검증

관찰과 판정의 충돌을 확인하고 필요한 재검사를 요청합니다.

AGENT 04업무 처리

수정 요청 초안을 정리하고 이전 검사와 재검수를 연결합니다.

에이전트는 실제 MCP 도구를 사용합니다. 불확실한 항목은 확인 필요로 남기고, 기준 확정과 최종 승인은 사람이 맡습니다.

LangGraph: 업무 분기·재개 / RAG: 문서 근거 검색 / DB: 확정 기준·버전·결과 저장. 전체 협업 흐름은 구현 예정입니다.

어떤 기준과 어디가 다른지 보여 주고, 수정 요청으로 연결합니다.

EXPECTED IMPACT → VALIDATION 05 / 06

더 빨리 확인하고,
더 분명하게 수정하도록 돕습니다.

기대효과는 아직 측정하지 않았습니다.
같은 사례를 수작업과 AI 보조 방식으로 처리해 비교합니다.

사용자에게 기대하는 변화확인할 지표검증 방법
검수자가 기준을 쉽게 확인기준 준비 시간·조건 누락률수동 작성과 AI 추출 후 사람 검토 비교
제작자가 수정할 내용을 이해요청 작성 시간·재질문·잘못된 요청같은 오류에 대한 수정 요청서 비교
담당자가 오류와 미검사를 구분위반 탐지 재현율·오통과율독립 원본 사례의 정답과 검사 결과 대조
승인자가 최신 결과로 결정버전 혼용·중복·구버전 승인 차단수정본·기준 변경·재시작 시나리오 시험
읽기: 기준과 근거를 이해한다.   쓰기: 구체적인 수정 요청을 만든다.   결정: 최신 검수 결과로 승인한다.

사람 작업 시간과 전체 처리 시간은 구분합니다. Ragas는 검색·설명 품질 평가에 사용하고, 실제 이미지 오판과 업무 완료는 별도로 평가합니다.
