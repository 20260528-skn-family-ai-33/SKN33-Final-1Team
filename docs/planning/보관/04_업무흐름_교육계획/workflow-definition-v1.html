광고 납품 검수와 보완 업무를 여러 에이전트가 나누어 처리하는 시스템

v0.1 · 1차 초안2026.10.02구현 전 설계

광고 납품 검수를 하나의 업무 흐름으로 연결합니다.

의뢰 조건을 정리하고, 납품물을 검사하고, 필요한 수정을 요청하고, 수정본의 해결 여부를 확인합니다. 담당자는 근거와 진행 상태를 확인하고 조건 확정·보완 확정·최종 승인을 수행합니다.

대표 시나리오
“딸기라떼 광고를 검수해줘” → 확정 조건 조회 → 문구·이미지·제작 근거 검토 → 오류 보고 → 보완 요청 → 수정본 재검수 → 최신 버전 사람 승인
사용자목표주요 행동권한 경계
발주·검수 담당자의뢰한 조건대로 납품되었는지 확인하고 보완을 관리한다.발주 등록, 조건 수정·확정, 검수 실행, 결과 검토, 보완 요청 확정최종 승인 권한이 부여된 경우에만 승인 가능. 조건 확정과 승인은 사람 행동으로 기록.
제작자납품물을 제출하고 지적된 항목을 수정한다.접근 가능한 발주 조회, 이미지·증빙 제출, 보완 작업 확인, 수정본 제출발주 조건을 임의 확정하거나 자신의 납품을 자동 승인하지 않음.

초기 사용자 역할은 두 가지로 제안합니다. 최종 승인 권한은 별도로 부여하며, 한 사람이 여러 역할을 맡더라도 권한·행동 이력은 구분합니다.

원본 광고 한 건에서 만든 6종은 개발·시연용입니다. 생성본의 실제 크기는 1254×1254이며 기존 기획의 1080×1080 규격 조건은 이 내용 전용 프로필에 적용하지 않습니다.

접수부터 승인까지, 아홉 단계의 책임을 나눕니다.

단계를 누르면 입력·처리·출력·저장 항목과 다음 경로를 확인할 수 있습니다.

ML/DL 학습의 1차 대상은 업무 요청 분류입니다. 아래 라벨은 제안이며, 실제 요청 문장을 수집하면서 경계를 검토합니다. 모델·기법·학습량·성능 목표는 아직 확정하지 않았습니다.

검수 이미지와 구조화 데이터를 분리 저장하고, 평가 정답은 별도 접근 영역에 둡니다. 이번 단계는 관계 초안이며 컬럼·키·인덱스·제약을 포함한 DB 설계 문서는 다음 작업에서 구체화합니다.

시연 데이터 사용 규칙

  • 모델 입력은 해당 이미지와 확정 조건입니다. 정답표·생성 프롬프트·이 문서는 검색/도구 입력에서 제외합니다.
