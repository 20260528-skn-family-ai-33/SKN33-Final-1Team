Motion
  Desktop >=900px wide and >=760px high: sticky scene with 340px scroll travel.
  Scene scale 1 -> 1.065, inner window 1 -> 1.12, window shift 0 -> -12px.
  requestAnimationFrame writes CSS variables; no React state update per scroll.
  IntersectionObserver reveals sections and preserves keyboard-focused content.
  Mobile/small windows and prefers-reduced-motion: fixed illustration, no sticky
  travel or zoom. Reduced-motion CSS also removes reveal transitions.
  Handlers, observers, and pending frames are cleaned up on unmount / StrictMode.

Run with your existing backend
  cd frontend
  npm run dev       # legacy, API proxy defaults to http://127.0.0.1:8000
  npm run dev:v1    # v1, requires the existing v1 backend setup
  Set API_PROXY_TARGET only if your backend uses a different local URL.
  Open the Vite HTTP URL printed in the terminal; do not open index.html via file://.

Scope boundary
  Revision-image comparison, revision requests, and human final-approval APIs
  are not implemented by this style change. Review completion and machine
  verdicts remain distinct from human approval. Landing artwork is labeled
  as an example, and visual test results are explicitly synthetic.
