## 숲결커피 브랜드 가이드 (1/2) 로고

### 로고 사용 원칙

- 로고는 가로세로 비율과 색을 변경하지 않는다.

- 로고는 원형 마크이며 글자 부분은 별도 워드마크로 쓴다.
