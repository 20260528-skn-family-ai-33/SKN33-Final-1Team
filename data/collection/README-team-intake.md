# 팀 보유 자료 접수 안내

실제 팀 보유 자료는 아직 제공되지 않았다. 아래 절차는 **2026-10-07 12:00
KST까지 접수하는 계획**이며 실제 접수·권리 확인·수량 재집계는 완료하지
않았다. 추가로 작성한 합성 자료를 실제 팀 업무 자료로 대체해 서술하지 않는다.

## 1. 접수 위치와 공개 범위

프로젝트 루트의 `.runtime/collection-team-input/`에 원문을 보관한다.
이 위치는 프로젝트 외부 비공개 입력용이다. Git에 원문을 추가하지 않으며
외부 공유·업로드도 하지 않는다. 현재 파일이 없다는 사실과 이후 접수 수량을
구분해서 기록한다. 실제 접수 전에 `.runtime/`이 Git 제외 대상인지 확인한다.

## 2. 필요한 자료와 함께 받을 정보

발주 의뢰서, 제작 가이드, 검수 체크리스트, 납품 광고 및 업무 요청 기록을
받을 수 있다. 파일마다 자료 종류, 출처/소유자, 수집일, 문서 버전, 공개 또는
내부 자료 여부, 사용 허용 범위와 확인 가능한 권리 근거를 함께 기록한다.
광고는 원본과 편집본 관계, 제작·편집 도구 및 제작시각도 확인한다. 업무
요청에는 필요한 최소 맥락만 유지하며 불필요한 이름·전화번호·메일은 제거한다.
모델 버전 또는 출처가 확인되지 않으면 unknown으로 기록한다.

원문을 받지 않았거나 사람이 검토하지 않은 사항은 완료로 표시하지 않는다.
합성 자료는 `raw/synthetic/`에 남겨 유형과 수량을 분리한다.

## 3. 접수 후 수행할 순서

1. 제공받은 원문을 비공개 입력 위치에 보관하고 파일 목록·해시를 기록한다.
2. 개인정보와 이용 조건을 점검한다. 비식별이 필요하면 원문을 덮어쓰지 않고
   작업 사본을 만들어 변경 이유를 남긴다.
3. 실제 문서·요청·광고의 수량과 원본 그룹 관계를 확인한다.
4. 합성 자료와 분리해 전체/추가분/필터 후 수량을 재집계한다.
5. 출처·품질·변경 이력을 보고서에 반영하고 사람 검토 상태를 유지한다.

접수 후 재집계 명령은 총괄 에이전트가 후속 구현할 예정이다. 현재는 해당
명령이 구현·실행되었다고 가정하지 않는다. 구현 후 확정된 실행 방법을 이
안내에 추가하고 실행 결과를 별도 증빙으로 남긴다.
