# 보존된 SigLIP2 기준 모델 학습

이 실행기는 표적 v2 학습을 사용하며 보존된 `siglip-ai-reviewed-v1-fp32` 선택 체크포인트로 초기화한다. 기존 데이터와 새 10장을 합친 `siglip-poster-plus10-v1` 패킷은 별도로 지정한다.

기존 `siglip-full-fp32`에서 삭제된 `lr3e-05-train_balanced/best.safetensors`만 지정된 기존 SHA-256일 경우 파일 부재를 허용한다. 이 체크포인트 바이트는 확인할 수 없으며, 해당 과거 모델을 새로 평가하지 않는다. 그 외 기존 선택 산출물, 프로토콜 체인, 실제 학습 출발점인 보존된 부분 파인튜닝의 검증은 그대로 유지한다. 코드 해시는 새 실행 프로토콜에 포함된다.

기존 평가 37장은 이미 노출된 데이터이며 독립 최종 평가셋이 아니다. 모델 선택은 개발셋에서 이뤄진다. 신규 10장 라벨은 AI 검토이고 이미지 이용 권한은 미확인이다.
