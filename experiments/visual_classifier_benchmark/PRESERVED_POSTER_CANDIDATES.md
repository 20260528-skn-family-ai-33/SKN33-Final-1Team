# 기존 포스터 데이터 보존과 신규 후보 검토 준비

`training_packets/siglip-poster-v2`의 원본 라벨 32개 수정, 기존 349개 추가 이미지, 개발셋 37개를 보존하는 검토용 디렉터리를 만든다. 패킷 전체의 무결성·기존 추가 이미지 경로·완료된 런팟 중복 검사 결과를 확인하고, 현재 후보와 업로드된 평가 후보 두 폴더의 이미지 중복을 다시 확인한다. 기존 패킷과 자료는 수정하지 않는다.

```bash
bash run_preserved_poster_candidates.sh preflight
bash run_preserved_poster_candidates.sh prepare
```

새 검토 폴더 `reviews/siglip-poster-plus10-v1`에는 기존 349개 추가 라벨과 이번 10개의 AI 검토 라벨이 들어간다. 이번 10개의 `APPROVED`는 사용자가 맡긴 AI 라벨 검토를 뜻하며 사람 검수나 이미지 사용 권한을 뜻하지 않는다. 실제 패킷 생성이나 훈련은 진행하지 않는다. 기존 32개 수정은 `train_corrections.csv`에서 유지된다. 파일 경로는 현재 RunPod의 기존 패킷 및 후보 폴더를 가리키므로 지우거나 이동하지 않는다.

완전 일치 및 근접 파일 검사는 모든 행사·디자인 가족이나 모델의 사전학습 자료를 식별하지 못한다. 신규 이미지의 사용 권한은 검증하지 않았으며 AI 라벨은 사람 검수가 아니다. 새 후보를 실제 패킷에 추가하기 전 각 이미지 이용 조건, 라벨, 그룹 및 출처를 확인한다. 여기에는 평가 데이터가 포함되지 않는다.
