# 포스터 보강 v2

새 학습용 포스터 22장(18개 관련 계열), 8개 라벨 CSV, 원본과384px 비교 화면을 담았다.
`review.html`에서 시각적 근거를 확인하고 `annotations.json`에서 공식 출처와 이용조건 기록을 확인한다.
양성·음성·모름 개수는 `dataset_summary.json`에 있다. 모름6셀은 학습 손실에서 제외한다.

기존 `siglip-openimages-v1`의 추가327장과 수정32셀은 부모 패킷에서 이어받는다.
이 폴더에 기존327장 전체를 다시 복제하지 않는다. 수정32셀 CSV만 바이트 그대로 포함해 상속 확인에 쓴다.
코드·명령어는 상위 [POSTER_AUGMENT_V2.md](../POSTER_AUGMENT_V2.md)를 따른다.

이 폴더는 완성된 `training_packet`이 아니다. `bash run_poster_augment.sh prepare`로 새 패킷을 만든 후 학습한다.
`package_manifest.json`은 이미지·CSV·검토 기록의 파일 해시와 정확한 부모 패킷 해시를 고정한다.
원본은 변형하지 않았고, `inputs384/`는 정규화 직전 RGB 검토용이다. GPU 텐서 캡처나 모델 추론 결과가 아니다.

출처표시 전용 공공누리 조건을 표기한 공식 게시물에서 원본을 받았으며 이미지별 원문·주소·표기를 기록했다.
제4유형 버스커 포스터와 보호 자료와 행사 계열 관계가 불명확한 로컬푸드 포스터는 이번 배포에서 제외했다.
APPROVED는 사용자가 요청한 AI 시각 검토의 학습 반영 상태다. 별도 사람 검수나 법률 검토 완료를 뜻하지 않는다.
