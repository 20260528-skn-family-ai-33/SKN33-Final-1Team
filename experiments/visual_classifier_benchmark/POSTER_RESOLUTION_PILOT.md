# 같은 포스터의 해상도 비교

기존 P160 `443×627`과 천안시 공식 블로그에서 공개된 같은 디자인의 `966×1366` 이미지를 비교한다. 큰 파일은 블로그 렌더링이며 인쇄 원본이라고 확인되지 않았다. JPEG와 PNG로 인코딩과 화질도 다르므로 원본 해상도 단독의 인과 효과로 주장하지 않는다. P160은 이미 본 시험 이미지이며 라벨은 AI 보조 검토다. 출처별 재사용 권한을 확인해야 한다.

기존 가중치·임계값, PaddleOCR worker와 탐지/인식 모델을 재사용한다. 학습·모델 다운로드·패키지 설치는 수행하지 않는다. 먼저 `preflight`를 실행하며 OCR 전용 Python·모델 디렉터리가 없다면 설치하지 않고 중단한다. 실제 모델 적재를 확인하는 것은 아니다.

이미지 모델은 원본 해상도에 관계없이 양쪽을 384×384로 변환하므로 고해상도 본체 처리 실험이 아니다. 원본 크기 차이와 전처리 결과의 영향을 탐색한다. OCR은 source 크기로 전달되지만 worker 내부 탐지 크기 제한이 적용된다. Qwen 이미지 모델은 이 실행에 포함되지 않는다.

OCR 결과는 해당 포스터에서 일부 수동 기재한 7개 기준 문구의 정규화 후 포함 여부로 진단한다. 전체 OCR 정답과 비해당 박스가 라벨링되지 않아 OCR 정확도·정밀도·F1은 계산하지 않는다. 시각 8라벨 셀 정확도와 마이크로 F1을 기록하되, 단 한 장으로는 8개 범주별 Macro F1을 신뢰성 있게 계산할 수 없어 비워 둔다. 시각 라벨 오류·누락을 함께 확인한다. 예열·반복 수가 적어 p95도 탐색적이다.

```bash
bash run_poster_resolution.sh preflight --packet /workspace/poster-resolution-p160-v1
bash run_poster_resolution.sh run --packet /workspace/poster-resolution-p160-v1
bash run_poster_resolution.sh show-results
```

`--ocr-python`, `--ocr-models`, `--ocr-device`, `--out`으로 이미 존재하는 환경과 새 결과 경로를 지정할 수 있다. 출력 폴더는 덮어쓰지 않는다. OCR 모델 적재와 예열을 제외한 요청 시간과 이미지 디코딩·384px 전처리·모델·동기화 시간을 각각 기록한다. 실행 중인 다른 GPU 모델에 따라 메모리 부족이나 속도 변동이 발생할 수 있다.
