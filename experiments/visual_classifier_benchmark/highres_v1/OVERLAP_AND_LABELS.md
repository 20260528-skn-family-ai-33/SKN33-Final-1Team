# 이미지 중복 및 라벨 검토 기록

- 187장 모두 Codex가 축소 모아보기로 1차 확인하고 작은 객체·경계 사례 일부를 확대해 검토했다. `labels.csv`의 각 이미지 근거는 요약이며, 전체 원본을 사람이 독립 검수하거나 라벨을 승인한 것은 아니다. `?` 12칸은 계산에서 제외한다. 행사명이나 출처 텍스트만으로 양성을 부여하지 않았다. 원본 이용 권리는 미확인이다.
- 로컬에 남아 있는 기존 원본 187장 및 과거 후보·추가 이미지 등을 합친 551개 파일 항목과 새 이미지 사이, 그리고 새 이미지끼리 SHA-256과 pHash/dHash로 후보를 대조했다. 일부 항목은 같은 이미지의 복사본이므로 551개를 유일한 이미지 수로 해석하지 않는다. 탐색 기준은 pHash 거리 ≤8 및 dHash 거리 ≤10 또는 동일 SHA-256이다. 결과는 중복 후보 탐지이지 중복 부재나 독립성의 증명이 아니다. 다른 원격 데이터셋에 대한 검사는 실행하지 않았다.
- `P001` 등 12장은 기존 포스터의 고해상도본이다. 기존 train 8장, dev 3장, test 1장으로 유지했다. dev/test 4장은 새 학습과 새 개발셋 모델 선택에 쓰지 않는다.
- `NEW018`은 기존 **train의 P112**와 같은 디자인으로 확인되어 `NEW029`와 함께 train으로 고정했다. `NEW001`과 `NEW017`은 동일 행사 포스터의 해상도 차이로 보고 같은 그룹에 두고 `NEW017`을 중복 학습·평가에서 제외했다. `NEW037`과 `NEW105`는 비슷한 교육 포스터여서 한 그룹으로 두었다. 행사·시리즈 및 같은 디자인 계열을 추가로 묶었으나 완전한 행사 중복 제거가 증명된 것은 아니다.
- 새 이미지 개발 26장, 시험 26장은 그룹을 나눠 둔 **잠정 비교용**이다. 학습에 쓰인 과거의 모든 이미지·행사와의 겹침이나 수집 편향이 해소된 독립 맹검 셋이라고 주장하지 않는다. 불꽃 양성은 개발과 시험에 각각 1장뿐이다.
- 기존 고해상도 교체 12장의 이전 승인 라벨과 이번 AI 초안의 차이는 `legacy_label_differences.csv`에 기록했다. 원래 승인 파일은 바꾸지 않았다. 새 초안의 판정과 기존 판정은 사람이 비교 검토할 수 있다.
- 데이터 구성: 187장 보관, 중복 1장 제외, 실험 대상 186장. 학습 130장(기존 train 8장 포함), 개발 26장, 시험 26장, 기존 dev 3장, 기존 test 1장. 기존 dev/test는 회귀 관찰에만 사용한다.
