# SigLIP 2 원본 해상도 조각 실험

2026-10-28 준비. 기존 포스터 원본·라벨·`cache-v1`·체크포인트·`run-002`는 수정하지 않는다. 새 코드와 결과를 별도 파일·폴더에 둔다. 설치나 원격 실행은 사용자가 직접 하지 않는 한 수행하지 않았다.

## 무엇이 달라지는가

- 각 원본 포스터의 EXIF 회전을 적용하고 원본 픽셀을 그대로 768×768 조각으로 나눈다. 마지막 가장자리 조각은 이전 조각과 겹칠 수 있으며, 포스터 전체를 덮는다. 768보다 짧은 변은 회색으로 채울 뿐 확대하지 않는다. 한 조각에 원본의 한 픽셀이 모델 입력의 한 픽셀로 들어가고 조각 자체를 축소하지 않는다.
- 포스터 전체를 384×384로 줄여 얻은 결과도 함께 사용한다. 항목마다 전체 화면 점수 75%, 조각 중 최대 점수 25%를 합친 뒤 판정한다. 점수는 확률이 아니라 시그모이드 적용 전 값(logit)이다. 이 비율은 시험셋을 보고 조정하지 않은 고정 실험값이며 최적이라고 보장하지 않는다. 조각이 많으면 잘못된 양성이 늘 수 있다.
- 라벨은 **포스터 전체에만** 있다. 조각 하나하나에 전체 라벨을 붙이지 않는다. 각 항목의 조각 중 최대 점수와 전체 점수를 합쳐 포스터 하나의 손실을 계산한다. `?`는 손실과 평가에서 제외한다.
- 메모리를 아끼기 위해 모든 조각은 기울기 없이 점수를 확인한 후, 각 항목의 최고 점수를 낸 조각만 다시 계산해 기울기를 구한다. 모델의 확률적 학습 동작을 꺼 두어 두 계산이 일치하도록 한다. `test_tiles.py`는 이 방식의 기울기가 전체 조각을 한 번에 미분한 결과와 일치하는지 확인한다.
- 기존 보존 SigLIP 2 가중치에서 출발해 뒷부분 4개 블록·pooling·분류기만 학습한다. 학습 130장/개발 26장을 사용하고 기존 시험 26장은 학습·개발 선택에 사용하지 않는다. 기존 dev/test 4장은 이번 조각 학습과 평가에 사용하지 않는다. 이전 데이터 전체 113장을 함께 재생하지 않으므로 기존 범위에서 성능이 떨어질 수 있다.
- 모델 선택은 개발 26장의 평균 F1을 우선하고 동률일 때 손실을 비교한다. 기존 384 모델도 후보에 포함하고 기존 임계값을 그대로 쓴다. 개발 결과가 낮으면 새 조각 모델 대신 기존 모델이 선택될 수 있다.
- 원본 187장 중 중복을 뺀 학습 130장은 2,869조각, 개발 26장은 591조각, 시험 26장은 484조각이다. 가장 큰 학습 이미지 한 장이 234조각이다. 기울기를 구할 조각의 재계산과 개발 평가도 있어 이전 실험보다 시간이 오래 걸리며 실제 소요 시간은 아직 측정하지 않았다.
- 이 시험 26장은 이미 이전 실험에서 살펴봤고 라벨은 AI 검토 초안이다. 완전히 독립된 시험 데이터가 아니며, 새롭게 수집하고 사람 검토를 마친 별도 데이터가 필요하다. 불꽃 양성은 1장뿐이다.

## RunPod 실행 개요

이미 업로드된 `run_v4.py`, `packet`, `cache-v1` 및 보존 기준 모델을 사용한다. 새로운 `run_tiles_v1.py`만 같은 `packet/code`에 업로드한다. `run_v4.py`의 SHA-256이 이전에 검증된 값과 같아야 한다. 차이가 있으면 중단한다. 사용자에게는 명령을 한 번에 하나씩 안내한다.

- `inventory`: 원본 데이터의 조각 수 확인. GPU·모델 불필요.
- `smoke`: 가장 큰 학습 포스터를 대상으로 234조각의 모델 로딩·전방 계산·역전파를 확인한다. 옵티마이저로 가중치를 업데이트하거나 결과 파일을 만들지 않는다. 실제 학습의 옵티마이저 상태는 추가 메모리가 필요하므로 이 점검이 OOM이 절대로 없음을 보장하지는 않는다.
- `train`: 새 실행 폴더만 생성해 포스터 단위 학습, 개발 평가, 선택 기록 및 새 가중치를 저장한다. 기본 최대 4회, 개선 없을 때 2회 연속이면 조기 종료한다.
- `evaluate`: 선택이 고정된 뒤 기존 모델과 선택 모델을 이전에 본 시험 26장으로 비교해 별도 결과 파일을 만든다. 독립 검증 성능이 아니다.

오류가 나면 출력과 새 폴더의 `status.json`을 확인한다. 실패한 폴더를 지우지 말고 새 이름을 사용한다. 절대 기존 원본·체크포인트 경로를 출력 경로로 쓰지 않는다.
